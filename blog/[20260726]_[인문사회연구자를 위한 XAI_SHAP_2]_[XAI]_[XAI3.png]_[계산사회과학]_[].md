# 사회과학자를 위한 XAI_SHAP

*「회귀분석 vs SHAP: 인문사회연구자를 위한 XAI 입문」(사이람) 유튜브 영상 기반 학습 노트(main source: https://www.youtube.com/watch?v=LWg3IE-RoKw&t=2221s)*


핵심 목표: SHAP을 단순한 시각화 도구가 아니라 예측모델을 해석하기 위한 방법론으로 정확히 이해하기

핵심 요약: SHAP은 “현실에서 X가 Y에 미치는 인과효과”를 설명하는 것이 아니라, “학습된 모델이 특정 예측을 만들 때 X를 얼마나 사용했는가”를 설명한다.


## SHAP의 핵심 개념

#### SHAP의 이름


"이 예측값이 나온 데 각 변수가 얼마나 기여했는가?"

머신러닝 관점에서 개별 케이스의 종속변수 Y를 예측하는데에 각 변수가 얼마나 기여했는가를 묻는 것이 SHAP의 목적이다.

SHAP은

SHapley Additive exPlanations

의 약자다.

핵심 아이디어는 게임이론의 Shapley value에서 가져왔다.

#### 게임이론으로 이해하기

다음과 같은 프로젝트가 있다고 하자.

세 사람이 함께 프로젝트를 수행했다.

프로젝트로 총 100만 원의 성과가 생겼다.

문제는 이것이다.

100만 원을 세 사람의 기여도에 따라 어떻게 공정하게 나눌 것인가?

각 사람의 기여는 혼자 했을 때와 함께 했을 때 다를 수 있다.

따라서 Shapley value는

가능한 여러 협력 조합에서 특정 플레이어가 추가되었을 때 성과가 얼마나 증가하는지를 계산한 뒤 평균을 낸다.

#### 머신러닝에서는 player가 feature다

SHAP에서는
```bath
게임이론	머신러닝
player	feature
coalition	feature 조합
payout	model prediction
Shapley value	feature contribution
```
가 된다.

예를 들어 모델이

어떤 청년이 취업 안정 집단에 속할 가능성 = 72%

라고 예측했다면 SHAP은

나이 때문에 얼마나 올라갔는가?

소득 때문에 얼마나 올라갔는가?

교육수준 때문에 얼마나 올라갔는가?

를 계산한다.

#### Shapley value 계산

어떻게 SHAP을 계산하는가?
1. 먼저 예측값 y의 평균값을 구한다. 그럼 우리가 개별 사례에서 y 값을 예측할 때 이 평균과 비교해서.. -> 왜 이 값은 평균보다 이만큼 낮은가? 이것을 각 변수별로 쪼개서 설명하는 것이다. 

2. 이를 측정하기 위해 각 개별 케이스마다 변수들의 조합을 여러개 만들어서 해당 변수가 포함될 때와 제외될 떄의 예측값의 차이를 반복 측정한다. -> 즉, 예측 결과값 자체의 변화를 추적하는 것이다. 

3. 2에서 나온 조합마다 나온 y의 변화량을 평균을 내어 각 변수의 최종 기여도(SHAP Value)를 확정한다. 여기서 +,- 즉, 예측값을 기준값 위로 밀어올린 변수와 아래로 끌어내린 변수들을 볼 수 있다. 

-> 그래서 SHAP은 개별 케이스별로 어떤 변수가 예측에 기여했는지 변수별로 계산을 해서, 개별 케이스 별로 나온 변수별 기여도를 평균을 내서 산춯한다. 즉, global을 구한다. 
이렇게 개별 데이터마다 산출된 SHAP 값의 절대값을 평균을 내면 **변수별 중요도**를 계산할 수 있다. 


feature (i)의 Shapley value는 개념적으로 다음과 같다.

```math
[
\phi_i =
\sum_{S \subseteq N\setminus {i}}
\frac{|S|!(M-|S|-1)!}{M!}
\left[
v(S\cup{i})-v(S)
\right]
]
```

핵심은 한 문장이다.

feature (i)가 여러 feature 조합에 추가되었을 때 예측값을 얼마나 변화시키는지를 모든 가능한 조합에 걸쳐 평균낸 값

이다.

#### SHAP에서 가장 중요한 식

SHAP을 사용하는 사회과학 연구자가 실제로 더 중요하게 기억해야 하는 것은 다음 구조다.
```math
[
f(x)=E[f(X)] + \sum_{j=1}^{p}\phi_j
]
```
즉

특정 사례의 예측값
=
기준 예측값
+
변수 1의 기여
+
변수 2의 기여
+
...
+
변수 p의 기여

이다.

#### Baseline이란 무엇인가

SHAP을 이해할 때 baseline은 매우 중요하다.

예를 들어 전체 사람들의 평균적인 예측 확률이

40%

라고 하자.

특정 사람 A의 예측 확률이

65%

라면 모델은 baseline보다

+25%p

높게 예측했다.

만약 해당 SHAP 구현이 실제 probability scale을 설명하도록 설정되어 있다고 가정하면 이를 개념적으로 다음처럼 설명할 수 있다.

```bath
baseline            40%

높은 사회적 지지     +12
이전 취업 경험        +9
높은 이동거리         -4
교육수준              +5
기타 변수             +3
-------------------------
prediction           65%
```

따라서 SHAP의 질문은

왜 65%가 되었는가?

이다.

#### SHAP 값의 부호

SHAP 값이
```math
[
\phi_j > 0
]
```
이면 해당 사례에서 그 feature가 baseline보다 모델 예측을 높이는 방향으로 기여했다.

반대로
```math
[
\phi_j < 0
]
```
이면 예측을 낮추는 방향으로 기여했다.

하지만 여기서 매우 중요한 주의가 필요하다.

SHAP 값 + = 현실에서 Y를 증가시키는 인과효과

가 아니다.

정확한 표현은

해당 관측치에서 모델의 예측값을 baseline 대비 높이는 방향으로 기여했다.

이다.




### 회귀계수와 SHAP은 무엇이 다른가

회귀계수는 다른 변수 통제시 어떤 변수가 1증가할 때 종속변수가 얼마나 증가하는 지를 의미한다.
반면, SHAP은 어떤 변수가 종속변수 y에 얼마나 기여했는지이다. 

즉, SHAP은 항상 머신러닝이 먼저 들어간다. 학습을 하고 학습된 모델이 예측한 y를 설명하기 위해, y를 예측할 때 각 x가 얼마나 기여했는지를 사후적으로 해석하기 위한 것이다.

그러므로 회귀계수와 분석의 층위가 다르다. 

또한, 인과관계 검증과 p 값이 만드시 필요한 연구라면 회귀분석이 필요하다. 하지만, 내가 연구하려는 데이터가 비선형 데이터이거나 개별 사례를 설명해야 한다고 하면 SHAP을 같이 사용할 수 있다. 

**주의할 점은 SHAP은 인과관계를 보여주는게 아니다. 기여도가 높다고 해서 그 변수가 원인이다? -> 이런 설명은 못한다**

또한, SHAP의 경우에도 다중공선성이 높다면, 그 기여도를 변수들끼리 나눠서 갖기 때문에 실제와 다를 수 있다. 변수끼리 상관이 너무 강하게 된다면 정리 또는 배제가 필요하다.



#### 핵심 비교

```bath
회귀분석	SHAP
변수와 결과의 관계를 모형화	모델의 예측을 설명
주로 global	local + global
계수 β	SHAP value φ
일정한 계수를 가정하는 경우가 많음	관측치별 기여도가 달라질 수 있음
통계적 추론 가능	일반적으로 통계적 유의성 검정 도구가 아님
p-value / CI	기본 SHAP에는 없음
선형성 가정 가능	비선형 모델 설명 가능
interaction은 명시적으로 넣는 경우가 많음	머신러닝이 학습한 interaction을 반영 가능
설명 중심	예측 설명 중심
```

### 회귀계수의 의미

다음 회귀모형을 생각하자.
```math
[
Y=\beta_0+\beta_1X_1+\beta_2X_2+\epsilon
]

(\beta_1=2)
```
라면 일반적인 선형모형에서

다른 조건이 동일할 때 (X_1)이 1단위 증가하면 Y가 평균적으로 2단위 증가하는 관계

로 해석할 수 있다.

단, 여기서도 곧바로 인과관계라고 말할 수 있는 것은 아니다.

인과해석을 위해서는 연구설계와 추가적인 가정이 필요하다.

### SHAP 값의 의미

어떤 개인 (i)에서
```math
[
\phi_{income}=0.8
]
```
이라는 결과가 나왔다고 하자.

이것은

소득이 1단위 증가하면 Y가 0.8 증가한다.

라는 뜻이 아니다.

정확한 질문은

이 사람의 현재 소득값이 이 모델의 현재 예측을 baseline에서 얼마나 이동시키는 데 기여했는가?

이다.

### 가장 중요한 차이
Regression coefficient
β_income

-> 보통 모델 전체에 하나 존재한다.

SHAP의 경우

φ_income(person 1)
φ_income(person 2)
φ_income(person 3)
...

사람마다 달라질 수 있다.

이 때문에 SHAP은 사회과학에서 특히

heterogeneity(다양성, 불균형)

를 탐색하는 데 흥미롭다.

#### 예시

세 사람이 있다고 하자.

```bath
사람	소득	SHAP_income
A	150	-0.30
B	300	+0.05
C	500	+0.45
```

SHAP은 모델이 각각의 사례에서 소득을 어떻게 활용했는지를 보여준다.

더 복잡한 모델에서는 다음처럼 될 수도 있다.
```bath
사람	소득	SHAP_income
A	150	-0.30
B	300	+0.35
C	500	+0.10

```
즉
```bath
소득 ↑ → 항상 예측 ↑
```
같은 단순한 선형관계가 아닐 수 있다.

이것이 머신러닝 + SHAP이 사회과학 연구에서 흥미로운 이유다.

### 그런데 SHAP이 회귀분석보다 “더 좋은” 것은 아니다

이 부분은 매우 중요하다.

잘못된 생각:

머신러닝은 최신 방법이다.
SHAP은 회귀분석보다 발전된 방법이다.

이렇게 이해하면 안 된다.

둘은 목적이 다르다.

질문 A

교육수준과 정치참여 사이의 평균적인 관계가 통계적으로 존재하는가?

→ 회귀분석이 적절할 가능성이 높다.

질문 B

다양한 사회경제적 특성을 이용하여 누가 정치참여 가능성이 높은지 예측할 수 있는가?

→ 머신러닝이 유용할 수 있다.

질문 C

높은 성능을 가진 머신러닝 모델이 각 사람의 정치참여 가능성을 판단할 때 어떤 특성을 사용했는가?

→ SHAP이 유용하다.


## 활용연구 현황

2020년 이후 SHAP 관련 논문 급격히 증가함. 이미 새로운 방법론을 넘어 사회과학 등 응용 분야 전반으로 확산되어 있다. 

사례 1: 직원 이직 예측 (Baydili, S.A. & Tasci, 2025)

연구질문
- 어떤 지원이 왜 이직할 가능성이 높은가?
- HR 부서가 개인 수준에서 이직 위험을 사전에 파악하고 맞춤 대응할 수 있는가?

연구방법
- 2개의 HR 데이터를 학습하여 이직 예측 모델
- SHAP Global: 전체 직원 대상 변수별 중요도 산출
- SHAP Local: 위험군으로 탐지된 개별 직원의 이직 동기 설명

사례 2: 역세권 개발과 주거 임대료 연구 (Peng, M. et al, 2025)

연구질문
역세권 개발 요소들이 주거 임대료에 미치는 비선형 효과와 변수 간 상호작용을 어떻게 설명할 수 있는가?

연구방법
- 머신러닝 학습 후 개별 관측치별 SHAP 값을 통해, 해당 주택의 임대료 예츠겡 가장 크게 기여한 변수를 확인
- SHAP 의존도 플롯으로 임계점과 변수 간 교호작용을 분석함. 
- 또한, 특정 샘플을 뽑아서 영향을 미친 요인을 그래프 형태로 시각화함 (예를 들어 공업단지에 위치한 A 주택 등..)


사례 3: 트위터  커뮤니티 진영 분류 (Bensilmance, S., Papsterigiou, T., Aze, j., Bringay, S., Servajean, M., & Mollevi, C., 2024)

연구질문
- 소셜 미디어 논쟁에서 찬/반 진영이 가각 어떤 언어 패턴으로 여론을 형성하는가?
- 네트워크 구조 뿐만 아니라 텍스트 자체에서 양극화 단서를 찾을 수 있는가?
(이 연구는 SHAP을 통해 구체적으로 어떤 단어가 이 진영으로 이 사람을 분류하는 데에 영향을 주었는가?를 확인할 수 있게 했다)

연구방법
- 리트윗 그래프 -> 찬/반 커뮤니티 분할
- 각 커뮤니티의 핵심 단어 추출 -> 핵심 단어와 커뮤니티 소속 패턴을 학습
- SHAP으로 진영 분류에 기여한 단어 식별

주요 연구 결과
- 반대 진영: 'destroying', 'liar' 등 사용 빈번
- 옹호 진영: 'freedom', 'brilliant' 등 지지 어휘
- 단어 수준을 넘어 '감정적 권위 어조'가 진영 구분의 강력한 예측 변수였음

조금 더 구체적으로 살펴보면, 특정 정치인에 대한 토픽으로 분류된 트윗글만 뽑아서 그 트윗글 사이의 리트윗 관계를 네트워크 그림으로 표현함. 정확히 찬반 진영으로 나뉜 것을 그림으로 확인할 수 있었음. 그래서 이 데이터를 통해 학습 데이터를 만든 것이다. 이렇게 학습된 모델에 SHAP을 추가하여서 왜 특정 트윗을 해당 진영의 사람으로 판별했는가를 설명했다.
-> 이를 통해 옹호 진영 단어들, 반대 진영 단어들을 나눠서 시각화할 수 있었다. 

-> 이처럼 여론 양극화, 텍스트 분석에 SHAP을 적용할 수 있다. SHAP을 통해 토픽 level에서 어떤 토픽이 이 사람을 해당 진영으로 분류할 수 있도록 영향을 줬다를 분석할 수 있게 한다.
