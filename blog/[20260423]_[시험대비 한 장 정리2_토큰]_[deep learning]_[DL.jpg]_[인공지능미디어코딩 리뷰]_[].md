# 2 토큰
토큰화란 무엇인가? 텍스트를 모델이 처리할 수 있는 작은 단위인 토큰으로 쪼개는 과정이다(초큰화 방식:단어기반, 형태소 기반, 문자기반, subword-**LLM이 사용하는 토큰화 방식**)
전통 NLP 전처리 과정: 텍스트 -> 토큰화 -> 정체 -> 형태소분석/표제어추출 -> 불용어 제거 -> 정규표현식기반 필터링 -> 인코딩 -> 패딩 : 좋은 전처리 = 좋은 성능이므로 FE 중심의 NLP
LLM 파이프라인: 텍스트 -> 토크나이저 -> Tokenids -> 모델입력
- 전통 NLP의 토큰 단위는 단어, 형태소이고 전처리 많이 필요하고 불영어 제거도 있어야 하며, 자기가 수집한 코퍼스로 vocab직접 구성해야 했고 인코딩도 따로 수행해야 했음
- LLM 시대 NLP에서는 토큰이 subword 기반이며, 전처리 거의 없고  불용어 제거 안하며 vocab가 모델에 내장되어 있고 인코딩은 토크나이저가 자동으로 해준다
- 모델마다 자기자신의 토크나이저, vocab 가짐.  -> 즉, 좋은 토크나이저 + vocab = 좋은 성능 모든LLM은'자기만의토큰사전(Vocabulary)'을 가진다.(즉, 같은 문장도 모델마다 다르게 쪼갠다. 이게 성능 차이 핵심원인임. 그러므로 한국어 잘하는 모델은 vocab에 한국어 토큰 즉, 한국어 서브워드가 충분히 포함된 모델)

subword 방식의 토크나이징 3자기 방법: BPE(빈도기반병합 - 자주 같이 나오는 글자를 합친다), WordPiece(확률기반선택-병합시 우도를 계산해서 우도가 가장 높아지는 쌍 선택-), Sentence Piece(공백 포함 전체 학습-공백을 _로 치환하여 전체 원문을 하나의 시퀀스로 토큰을 학습) - 공통점: 단어가 아니라 subword 단위로 쪼개서 OOV 문제 해결하고 vocab 크기 제한함. 결국 쪼개는 규칙과 토큰 사전만 다를 뿐이지, 모두 subword tokenizer이다
BPE 작동원리: 1. 문자 단위로 분해 2. 빈도 높은 쌍 병합 3. 어휘 사전 구축 4. 처음 보는 단어도 subword로 분해해서 처리(신조어도 토큰화 -> 임베딩 가능)

왜 vocab가 중요한가? 1. 토크나이저와 vocab에 따라 같은 문장도 다르게 분할 한다. 토큰의 분할 방식 vocab 구성 자체가 모델 성능에 직결한다. (코드 잘하는 모델은 vocab에 코드 토큰이 많은 것이다) -> LLM은 전처리를 줄이고 토크나이저와 vocab에 모든 것을 맡긴다.
> NLP에서 vocab는 모델이 세상을 바라보는 지능의 범위를 결정한다. 딥러닝 모델은 텍스트를 vocab에 매핑된 고유한 정수 인덱스 시퀀스로 변환해서 처리한다. 그러므로, 어떤 토큰이 vocab를 구성하는 지에 따라서 모델의 인식이 달라진다. 정교하고 풍부한 또는 내가 분석하고자 하는 언어의 토큰에 맞게 설계된 vocab는 언어 이해 생성과 능력 전반의 토대이다. 

토크나이저는 단순 전처리가 아니라 언어를 어떻게 분해해서 인식할 것인가라는 철학이다.
