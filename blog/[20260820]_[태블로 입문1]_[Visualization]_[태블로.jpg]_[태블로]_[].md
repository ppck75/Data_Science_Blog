# 태블로를 이해해보자

데이터 리터러시란? 

데이터를 보는 것이 아니라, 탐색을 통해 자신이 이해하고, 이를 다른 사람과 대화와 협엽을 통해 찾은 통찰을 공유하는 능력이다.

태블로 시각화 하기 이전: 데이터를 다운로드 받고 -> 엑셀로 가공 -> 파워포인트로 시각화

태블로 도입: 데이터를 태블로에서 바로 연결하여 실시간으로 데이터의 흐름 추적 -> 테블로에서 분석 -> 테블로 서버로 공유함

## 태블로란

데이터를 분석 및 시각화하는 BI 솔루션이다.

-> 누구나 쉽게 사용할 수 있는 직관적인 BI 분석 솔루션이다. 태블로는 사용성이 편리하고 시각성도 뛰어나다. 

장점

1. Drag Drop으로 데이터 시각화가 가능하다. 
2. 데이터 원본에 없는 필드를 만들 수 있다.
3. 다양항 시각화가 가능하다. 

## 태블로 기초

'#' -> 숫자 타입  더블 클릭하면 SUM이 붙어있다.-> 측정 방식 기본값에 합계가 붙어있기 때문이다!

'측정값' 일반적으로 숫자이고, 핵션을 통해 설정된 집계에 따라 차트를 만들게 된다


- 좌측 테이블에 보면 차원이 나눠져 있다.
- 차원은 그 숫자로 만들어진 차트를 어떻게 나눠서 볼 것인지를 결정한다. 


### 막대차트
1. 만들기 쉽다
2. 항목별로 나눠서 보는데 적합하다
3. 카테고리(범주), 순위, 추세를 보는데 유용하다

그런데, 태블로에서는 측정값 한 덩어리를 두고 이것을 세부적으로 나눠서 보도록 설계되어 있기 때문에, 기본적으로 막대로 먼저 시작한다. 


### 평균 등을 기준으로 그래프의 색상 구분하기 

좌측 하단에 오른쪽 클릭 -> 계산된 필드 만들기 -> 제목 만들고 계산함수 입력하기. 

(예를 들어 서울시 범죄 관련 공공 데이터에서)
```bash
SUM([강간·강제추행 발생]) >= WINDOW_AVG(SUM([강간·강제추행 발생]))

// 매출이 평균 이상이면 Ture로 반환이 되며, 매출이 평균 미만이면 False로 반환된다. 
```

-> 그 후 평균 이상 미만으로 만들어진 값을 좌측에서 색상에 드래그하면 색상이 구분된다 (평균라인도 테이블 참조선에 넣어서 그릴 수 있다)
