# 데이터 분석의 핵심, 특성 공학(Feature Engineering) 이해하기

머신러닝 모델의 성능을 결정짓는 가장 중요한 요소는 모델 그 자체보다 '어떤 데이터를 넣느냐'이다. 이를 흔히 **특성 공학(Feature Engineering)**이라 부른다. 특성 공학은 단순히 데이터를 고르는 작업에 그치지 않고, 모델이 학습하기 가장 좋은 형태로 데이터를 가공하는 모든 과정을 포함한다. 크게 세 가지 단계로 나누어 이해할 수 있다. (내가 이전에 알고 있던 부분인 어떤 feature를 넣을 것인가?만이 아니라, 어떻게 손질할 것인가?와 새로운 재료를 만들 것인가?까지 포함하는 개념이 Feature Engineering이다.)

---

## 1. 특성 선택 (Feature Selection): "무엇을 넣을 것인가?"
가장 기본이 되는 단계로, 수많은 데이터 중 모델의 예측에 실질적으로 도움이 되는 변수만을 골라내는 과정이다.

* **설명**: 모델에 입력할 특성(x)을 결정하는 단계이다.
* **예시**: 집값 예측 모델을 만들 때, '집의 위치'나 '평수'는 중요하지만 '전 집주인의 이름'은 예측에 도움이 되지 않으므로 제외하는 것이다.
* **목적**: 불필요한 노이즈(Noise)를 제거하여 모델을 더 가볍고 정확하게 만든다.

---

## 2. 특성 변환 (Feature Transformation): "어떻게 손질할 것인가?"
선택한 재료를 모델이 이해하기 쉬운 형태로 변형하는 과정이다. 사회과학 데이터 분석에서 자주 쓰이는 **로그 변환($\log(x)$)**이 대표적인 사례이다.

* **왜 하는가?**: 선형 회귀와 같은 모델은 데이터가 종 모양의 **정규분포**를 따를 때 최상의 성능을 발휘한다.
* **사회과학 데이터의 특징**: 소득, 인구수, SNS 리트윗 수 등은 일부가 매우 큰 값을 가지는 '오른쪽으로 꼬리가 긴 분포'를 띠는 경우가 많다.
* **해결법**: 이때 로그를 취하면 큰 값들이 안으로 모이면서 데이터가 정규분포에 가까워진다. 이를 통해 모델은 데이터의 규칙을 훨씬 더 쉽게 파악하게 된다.

---

## 3. 특성 생성 (Feature Creation): "새로운 재료를 만들 것인가?"
기존에 있던 변수들을 조합하여 모델에 새로운 통찰을 줄 수 있는 새로운 변수를 만들어내는 과정이다.

* **설명**: 개별 특성들을 결합하여 더 의미 있는 정보를 창출하는 단계이다.
* **예시**: '방 개수'와 '거실 크기'라는 각각의 변수 대신, 이를 더하거나 곱해서 '전체 실평수'라는 새로운 변수를 만드는 것이다.
* **수식 사례**: $x_3 = \log(x_1 x_2)$와 같이 기존 변수 x1과 x2를 조합하여 새로운 특성 x3를 생성하는 것이 이에 해당한다.

---

## 💡 요약하자면
특성 공학은 단순히 좋은 재료를 고르는 것에서 끝나지 않는다. **"모델이 가장 맛있게 요리할 수 있도록 재료를 씻고, 썰고, 양념하는 모든 과정"**을 의미한다.

1.  **고르기**: 특성 선택 (Feature Selection)
2.  **손질하기**: 특성 변환 (Feature Transformation)
3.  **조합하기**: 특성 생성 (Feature Creation)
