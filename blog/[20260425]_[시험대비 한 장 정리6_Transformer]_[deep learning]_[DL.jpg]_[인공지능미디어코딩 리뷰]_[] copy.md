# Transformer
RNN/LSTM은 시퀀스를 순차적으로 처리 -> 병렬처리 불가능(느림), 긴 문장에서 정보손실(LSTM으로도 해결X). seq2seq의 contect vector 명목 문제(아무리 긴 문장도 하나의 벡터로 압축) -> 트랜스포머가 해결: selfattention으로 모든 단어간 관계 한번에 계산>병렬처리, 거리무관(아무리 멀리 떨어진 단어도 쌍대비교로 직접 관계 파악), 인코더디코더 구조 요지(seq2seq 구조는 유지하되 RNN을 attention으로 완전 대체)
인코더: 입력 시퀀스를 문맥화된 표현으로 변환(같은 구조 6층 반복, 전체입력 동시에 병렬 처리) / 디코더: 인코더 출력 참고하여 시퀀스 생성(한 단어씩 순서대로, 미래단어는볼수X)
입력 임베딩(각 단어 토큰을 512차원의 숫자 벡터로 변환)+위치인코딩(순서 정보가 사라지는 문제 해결. 각 위치에 고유한 신호 더한다.RNN은 없음)
어텐션 매커니즘의 QKV 행렬연산(각각 입력벡터와 w_q,w_k,w_v와 행렬곱해서 생성.이 값들은 모두 학습으로 결정-모델이 훈련하면서 어떤 관계를 잘 봐야 맥락을 잘 파악하는 context vector를 만들 수 있을 지 스스로 학습한다)
QKV 행렬연산: QKV 행렬의 행 하나하나가 그 위치에 있는 단어의 q,k,v벡터임
과정: 나의질문(Q)와 문장 내 모든 단어의K를 내적한다. 나온 점수들을 softmax로 확률로 변환한다(0~1사이) 이게 바로 attention score이다. 위에서 구한 점수를 모든 단어의 실제값인 V에 각각 곱하여 모두 더한다. 이게 attention value이다. (score(스칼라): 어떤 단어를 얼마나 중요하게 볼 것인가?즉, 특정 단어가 다른 단어들에게 주는 가중치, value:V까지 곱해서 더해서 입력 벡터와 같은 차원을 가진 하나의 벡터, context vector: attention value가 곧 컨텍스트 벡터 역할을 수행) (각 V벡터와 가중합하여 어텐션 값(Attention Value)을 구합니다. 이를 단어 I에 대한 어텐션 값 또는 단어 I에 대한 컨텍스트 벡터(context vector)라고도 할 수 있습니다.)
Q와 K를 내적해서 유사도 점수를 구함(값이 클수록 관련있음) / √d_k로나누기:스케일링(값이 너무 크면 softmax가 너무 한 곳에만 몰리니까) / softmax:확률분포로변환(모든 score의 합이 1이 되는 확률로 변환) / 가중치로 V를 곱해서 합산(관련 정보가 반영된 새로운 벡터 탄생)
인코더-디코더 attention:Q는 디코더,KV는 인코더에서(두 개의 다른 시퀀스 간의 관계를 보고 번역할 때 원문의 어디를 볼까?) / self attention: QKV 모두 같은 시퀀스에서(한 문장 안의 모든 관계를 스스로 파악) attention은 거리무관(멀리 떨어져도 직접 연결), 병렬처리(모든 단어 쌍의 관계를 동시 계산), 해석 가능성(가중치(attention score) 시각화로 모델의 주목점 확인가능)
멀티헤드어텐션: 하나의 헤드가 하나의 관점 포착. 언어에는 여러 종류의 관계가 있기에 멀티헤드로 봐야함> QKV를 8개의 헤드로 분할(512/8=64차원) 각 헤드가 서로 다른 공간에서 독립적으로 셀프어텐션 계산, 이때 8개 헤드가 동시에 수행하여 병렬 처리. 각 헤드는 서로 다른 패턴 학습->8개 출력을 이어붙어 512차원으로 만들고, 선형변환(W0:head의 출력을 합한 행렬은 최종 출력으로 변환하는 가중치 행렬임. 즉,서로 다른 8개 헤드를 잘 섞고 다듬어주는 W_o)을 한 번 더 거쳐 최종 멀티헤드어텐션을 출력한다. MultiHead(Q,K,V) = Concat(head_1, …, head_8) × W_O (즉, 멀티헤드어텐션 박스에는 W_q,k,v와 w_o가 있고, FFNN에는 w1,w2...가 있다. 모두 학습 대상)
인코더 순서: 1.멀티헤드셀프어텐션(모든단어가 서로 바라보며 관계 파악)>2.add,norm(잔차연결: 원래 입력을 다시 더해 정보 손실 방지, Norm: 숫자 스케일을 일정하게 맞춰 안정화)>3. position-wise FFNN(각 단어의 표현을 개별적으로 풍부하게. 512>2048>512 확장 축소하여 비선형 패턴 학습)>4. add,Norm(매 단계마다 진행하여 학습 안정성 확보) 1층은 단어 수준 관계 파악이라면 6층은 문장 전체의 의미와 뉘앙스를 이해하며 점점 깊이 이해한다. (결과: 각 단어가 문맥을 풍부하게 담은 벡터로 변환된다!)
디코더 순서: 1. 출력 임베딩+위치인코딩(지금까지 생성한 출력 단어들을 벡터로 변환) 2. masked(미래단어 못 보게 마스킹) 3. add&norm 4. 인코더디코더cross attention 5. add&norm 6. FFNN(각 단어 표현을 풍부하게) 7. add&norm --> 핵심: masked attention과 인코더에게 물어보는 cross attention  디코더 처음에 sos 입력하면 인코더의 출력 참조해서 i 생성한다. 그런 다음 sos i 입력해서 생성하고 반복.. 결국 eos 생성하면 끝. 인코더는 입력 전체를 '동시에' 이해하고, 디코더는 하나씩 생성하면서 필요할 때 인코더 참고
