# 사회과학자를 위한 XAI_SHAP

*「회귀분석 vs SHAP: 인문사회연구자를 위한 XAI 입문」(사이람) 유튜브 영상 기반 학습 노트(main source: https://www.youtube.com/watch?v=LWg3IE-RoKw&t=2221s)*


핵심 목표: SHAP을 단순한 시각화 도구가 아니라 예측모델을 해석하기 위한 방법론으로 정확히 이해하기

핵심 요약: SHAP은 “현실에서 X가 Y에 미치는 인과효과”를 설명하는 것이 아니라, “학습된 모델이 특정 예측을 만들 때 X를 얼마나 사용했는가”를 설명한다.


## 왜 사회과학자가 XAI를 배워야 하는가

*회귀분석은 해석이 매우 직관적이다. 그래서 가설검정에서 표준적으로 많이 사용하는 방법이다.*

1.1 사회과학자가 익숙한 질문

전통적인 사회과학 연구에서는 흔히 다음과 같은 질문을 한다.

- 교육수준이 정치참여에 영향을 미치는가?

- 소득이 삶의 만족도와 관련되어 있는가?

- 사회적 지지가 우울감과 관계되는가?

이 질문들은 대체로 변수 간 관계를 추정하고 설명하는 문제다.

그래서 다음과 같은 모형을 사용한다.

```math
[
Y_i = \beta_0 + \beta_1X_{1i}+\beta_2X_{2i}+\cdots+\epsilon_i
]
```

연구자는 주로 다음을 확인한다.

```bath
회귀계수
계수의 방향
표준오차
신뢰구간
p-value
통제변수를 넣었을 때 계수가 어떻게 변하는지
```

즉 전통적인 사회과학 통계모형은 대체로 추론(inference)​에 강하다.

소득과 만족도의 경우를 살펴보자. 실제 데이터를 보면 소득이 일정 수준 넘어가면 만족도가 더이상 올라가지 않는 구간이 있다. 소득이 올라도 만족도는 그만큼 비례해서 오르지 않는다. **그래서 회귀분석은 이러한 패턴 변화 지점을 확인하기 어렵다는 한계가 있다.**


### 회귀분석이 답하기 어려운 질문

1. B 계수는 선형 관계만 가정이다. 포화 역전 구간의 정밀한 패턴 포착 어렵다
2. 각 변수의 B는 독립적 평균 효과이다. 즉, 다른 변수를 통제했을 때 특정 변수의 효과를 독립적으로 보는 것이다. 그래서 변수 간 조합 효과는 교호작용항을 따로 넣어야만 보인다.
3. 개별 관측에 대한 패턴을 알기 어렵다. 회귀분석은 전체 데이터에 대한 평균효과이다. B 는 전체 샘플의 평균 효과인데, 특정 관찰값에 어떤 변수가 얼마나 영향을 미쳤는지 설명이 불가하다.

-> 이를 머신러닝과 SHAP으로 보완이 가능하다.


머신러닝은 질문이 조금 다르다

머신러닝에서는 질문을 다음처럼 바꾸는 경우가 많다.

```bath
어떤 청년이 취업 안정 집단에 속할지를 얼마나 정확히 예측할 수 있는가?

어떤 학생이 중도탈락 위험이 높은가?

어떤 응답자가 정책을 지지할 가능성이 높은가?
```

여기에서는 관심이

“변수의 평균적인 관계가 무엇인가?”

에서

“새로운 사례의 결과를 얼마나 정확하게 예측할 수 있는가?”

로 이동한다.

따라서 머신러닝에서는 흔히 다음을 중요하게 본다.

```bath
Accuracy
Precision
Recall
F1 score
ROC-AUC
RMSE
MAE
test-set performance
cross-validation performance
```

### 머신러닝의 주요 장점

1. 선형 관계를 사전에 가정하지 않아도 자동으로 발견한다. 또 꺾임, 포화 구간 패턴도 알고리즘이 직접 학습하게 된다. 즉, y 값을 가장 잘 예측하는 규칙을 찾아낸다.
2. 변수간의 조합 효과도 교호작용항 설계 없이 패턴을 포착 가능하다. 
3. 통계적 가정이 불필요하다. 정규성, 등분산성, 다중공선성 등 제약에서 자유롭다(왜? 머신러닝 목적은 y를 얼마나 잘 맞추냐! 이기 때문이다. 그래서 p-value 등 없다)-> 전통적 통계 가정에 덜 의존적이다. 


**문제: 좋은 예측모델은 이해하기 어렵다**

예를 들어 Random Forest나 XGBoost가 로지스틱 회귀보다 훨씬 좋은 예측 성능을 보였다고 하자.

문제가 생긴다.

```bath
왜 이 모델은 이 사람을 고위험 집단이라고 판단했는가?

어떤 변수가 예측에 가장 많이 사용되었는가?

변수의 값이 높아질수록 예측은 어떤 방식으로 달라지는가?

동일한 변수라도 사람마다 영향이 다른가?
```

복잡한 머신러닝 모델에서는 이런 질문에 답하기 어렵다.

이를 흔히 black box problem이라고 한다.


머신러닝 모델은 왜 예측을 했는지 말해주지 않는다. 예측 성능은 측정할 수 있는데.. 왜 이 사람이 행복하다고 예측을해..? -> 이게 머신러닝 방법론에 들어가 있지 않다. 

이 부분을 설명하기 위해 등장한 것이 XAI이다. 이로 인해 머신러닝의 블랙박스성을 분해해서 설명할 수 있도록 한다. 

### XAI가 설명하는 수준

1. 전연적 설명: 어떤 변수가 모델 전반에서 예측에 많이 기여했는가?
2. 국소적 설명: 이 개별 관측지(사례)가 왜 이런 예측 결과가 나와쓴ㄴ가?

이렇게 global, local한 두 가지 축의 설명이 XAI를 통해 가능하다!

XAI는

Explainable Artificial Intelligence

즉,

설명 가능한 인공지능

을 의미한다.

핵심 질문은 매우 간단하다.

모델이 왜 이런 예측을 했는가?

SHAP은 이 질문에 답하기 위한 대표적인 방법 가운데 하나다.

Lundberg와 Lee는 2017년 SHAP을 제안하면서 복잡한 모델의 특정 예측에 대해 각 feature가 기여한 정도를 할당하는 통합적 설명 프레임워크를 제시했다.



## SHAP을 배우기 전에 반드시 알아야 할 머신러닝 기초

### 지도학습


데이터가 다음처럼 있다고 하자.
```bath
나이	소득	학력	사회적 지지	취업 안정
24	180	16	3.2	0
29	310	16	4.1	1
32	350	18	4.5	1
```
여기에서

나이
소득
학력
사회적 지지

는 feature / predictor / input variable

이고,

취업 안정 여부는

target / outcome / label

이다.

사회과학 용어로 바꾸면 대략

독립변수 → feature
종속변수 → target

으로 생각할 수 있다.

하지만 완전히 같은 개념은 아니다.

머신러닝에서 feature는 반드시 이론적 독립변수라는 의미를 갖지는 않는다.

### 학습과 예측

지도학습의 기본 흐름은 다음과 같다.

데이터
  ↓
입력변수 X + 결과변수 Y
  ↓
훈련 데이터(training data)
  ↓
머신러닝 모델 학습
  ↓
새로운 데이터
  ↓
예측

이를 함수로 표현하면

```bath
[
\hat{Y}=f(X)
]
```

이다.

머신러닝의 핵심은 결국

X를 보고 Y를 예측하는 함수 f를 학습하는 것

이다.

SHAP은 이 함수 (f)를 설명한다.

### SHAP보다 먼저 모델 성능을 확인해야 한다

매우 중요한 원칙이다.

예측하지 못하는 모델을 정교하게 설명해봤자 연구적으로 큰 의미가 없다.

따라서 연구 순서는

```bath
모델 구축
↓
모델 성능 평가
↓
모델이 충분한 예측력을 갖는지 확인
↓
SHAP 분석
```
이어야 한다.

절대로
```bath
SHAP 그림부터 출력
↓
중요 변수 발견
↓
논문 작성
```
이 되어서는 안 된다.

### 훈련 데이터와 테스트 데이터

머신러닝 연구에서 흔한 구조는

```bath
전체 데이터
│
├─ Training set
│    모델 학습
│
└─ Test set
     최종 성능 평가
```

이다.

또는 training data 내부에서 cross-validation을 수행한다.



## XAI의 큰 지도

XAI를 크게 나누면 두 축을 생각하면 된다.

#### Intrinsically interpretable model (모델 자체가 해석 가능)

대표적으로

선형회귀,
로지스틱 회귀,
작은 decision tree

등이 있다.

모델 구조 자체가 비교적 이해하기 쉽다.

#### Post-hoc explanation

복잡한 모델을 먼저 만든 뒤,

사후적으로 모델의 행동을 설명한다.

대표적인 방법이

SHAP,
LIME,
permutation importance

등이다.

SHAP은 이쪽에 해당한다.

### 전체 모델을 설명하는가, 한 사례를 설명하는가

또 하나 중요한 구분이다.

Global explanation:

전체 데이터에서 모델이 어떤 변수를 중요하게 사용하는가?

Local explanation:

이 특정 사람의 예측에서는 어떤 변수가 중요했는가?

SHAP의 큰 장점은

local explanation에서 출발해 global explanation까지 확장할 수 있다는 것이다.
