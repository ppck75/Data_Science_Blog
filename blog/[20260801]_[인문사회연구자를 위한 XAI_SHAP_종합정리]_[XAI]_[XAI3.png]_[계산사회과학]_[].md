# 인문사회연구자를 위한 XAI와 SHAP 종합정리

> 이 글은 「XAI: 인공지능의 블랙박스와 불투명성」 실습 노트와 「인문사회연구자를 위한 XAI·SHAP」 1·2편을 하나의 연구 흐름으로 재구성한 글이다. 개념 설명에는 메타코드 모델링 기초 강의 필기와 [사이람의 「회귀분석 vs SHAP: 인문사회연구자를 위한 XAI 입문」](https://www.youtube.com/watch?v=LWg3IE-RoKw&t=2221s)을 참고했다.


인문사회연구자가 XAI를 사용할 때 가장 먼저 해야 할 일은 화려한 시각화를 만드는 것이 아니다. 연구 질문이 관계에 관한 것인지, 예측에 관한 것인지, 아니면 이미 만들어진 예측을 설명하려는 것인지 구분하는 일이다. 이 구분이 선행되어야 회귀분석과 머신러닝, SHAP의 역할을 혼동하지 않을 수 있다.

또한, XAI는 사회과학의 좋은 보완이 될 수 있다. **사회과학에서 가장 중요한 것은 설명 가능성이다.** 즉, 변수 X와 변수 Y사이의 관계를 설명하는 것이 사회과학의 주된 목적이자 설명력이다. 물론, 사회과학 역시 '예측'을 지향하지만, 예측력은 조금 떨어지더라도 설명 가능성을 더욱 중시한다. 딥러닝 등을 활용한 방법론이 등장
한 현 시점에도, 여전히 전통적 연구 방법론인 '회귀분석'을 사용하는 이유는 바로 이것에 있다. 회귀분석은 복잡한 딥러닝 기반 모델보다는 예측 정확도(또는 지표)가 떨어지지만, 그럼에도 불구하고 '설명 가능'한 통계 분석 방법론이기 때문이다.         

        이러한 사실은 한편으로 인공지능, 딥러닝, 머신러닝 등 CSS 방법론을 통한 연구를 진행할 때 사회과학 연구자는 모델의 설명가능성을 확보하기 위해 고민해야 함을 시사한다.

결국, 인공지능의'블랙박스성'을 설명하고자 시도하는 XAI는 설명가능성을 중시하는 사회과학의 연구에 좋은 보완이 될 수 있는 것이다!!

오늘 블로그 글은 인문사회연구자가 알아야할 XAI의 여러 방법들과 그 중 대표적인 SHAP에 대해서 자세히 다뤄보고자 한다.

## 1. 관계, 예측, 예측 설명은 서로 다른 연구 질문이다

전통적인 사회과학 연구는 흔히 다음과 같은 질문을 다룬다.

- 교육수준은 정치참여와 어떤 관계가 있는가?
- 소득은 삶의 만족도와 관련되는가?
- 사회적 지지는 우울감과 어떤 관계를 갖는가?

이때 연구자는 회귀계수의 방향과 크기, 표준오차, 신뢰구간, p값, 통제변수 투입에 따른 계수 변화를 살펴본다. 일반적인 선형회귀 모형은 다음처럼 표현할 수 있다.

$$
Y_i = \beta_0 + \beta_1X_{1i} + \beta_2X_{2i} + \cdots + \epsilon_i
$$

이 접근은 변수 간 평균적인 관계를 추정하고 통계적으로 추론하는 데 강하다. 그러나 관계가 꺾이거나 포화되거나 역전되는 경우, 여러 변수가 복잡한 방식으로 결합되는 경우, 개별 사례마다 관계가 다르게 나타나는 경우에는 사전에 함수 형태와 교호작용을 충분히 지정해야 한다.

머신러닝은 질문의 중심을 새로운 사례의 결과를 얼마나 잘 예측하는가로 옮긴다. 예를 들면 다음과 같다.

- 어떤 학생이 중도탈락 위험이 높은가?
- 어떤 응답자가 특정 정책을 지지할 가능성이 높은가?
- 어떤 문서가 특정 정치적 입장으로 분류되는가?

머신러닝에서는 정확도, 정밀도, 재현율, F1, ROC-AUC, RMSE, MAE, 교차검증 성능, 테스트 데이터 성능 등이 중요하다. 복잡한 비선형 관계와 변수 조합을 유연하게 학습할 수 있지만, 높은 예측 성능이 곧 이해 가능한 설명을 제공한다는 뜻은 아니다.

XAI는 여기에서 세 번째 질문을 담당한다.

> 충분한 예측 성능을 보인 모델은 왜 이런 예측을 만들었는가?

따라서 연구의 세 층위는 다음처럼 구분해야 한다.

| 연구 목적 | 핵심 질문 | 대표적인 결과 |
| --- | --- | --- |
| 관계 추론 | X와 Y는 어떤 평균적 관계를 갖는가? | 회귀계수, 신뢰구간, p값 |
| 예측 | 새로운 사례의 Y를 얼마나 잘 맞히는가? | 테스트 성능, 교차검증 성능 |
| 예측 설명 | 학습된 모델은 이 예측에 어떤 변수를 사용했는가? | 중요도, PDP, SHAP 값 |

머신러닝은 전통적인 모수 모형의 정규성이나 선형성 가정에 덜 의존할 수 있지만, 아무런 가정도 필요하지 않은 것은 아니다. 표본의 대표성, 측정의 타당성, 훈련·테스트 분리, 데이터 누수 방지, 새로운 자료에 대한 일반화 가능성은 여전히 연구 결과의 타당성을 좌우한다.

## 2. 블랙박스와 불투명성은 무엇인가

블랙박스는 단순히 모델이 복잡해서 보기 어렵다는 뜻이 아니다. 입력에서 출력으로 가는 함수는 계산 가능하지만, 고차원 비선형 관계와 수많은 상호작용으로 구성된 내부 추론을 인간이 의미 있는 개념으로 압축하기 어려운 상태를 뜻한다.

이 불투명성은 흔히 예측 성능을 높이는 과정에서 커진다. 선형회귀나 작은 의사결정나무는 구조를 비교적 쉽게 읽을 수 있지만, 랜덤포레스트·그래디언트 부스팅·XGBoost와 같은 복잡한 모델은 많은 규칙과 상호작용을 결합한다. 모델 구조가 복잡해질수록 예측력이 향상될 수 있는 반면, 판단의 근거를 한눈에 설명하기는 어려워진다.

사회과학 연구에서 불투명성은 다음 문제로 이어진다.

1. 연구자는 모델이 사회적 범주와 측정변수를 어떤 방식으로 사용했는지 설명하기 어렵다.
2. 높은 성능만으로는 특정 집단이나 사례에 대한 예측이 타당하고 공정하다고 판단할 수 없다.
3. 공공정책·의료·금융·교육·채용처럼 결정의 근거를 설명해야 하는 영역에서는 책임성과 검토 가능성이 부족해진다.
4. 모델이 이론적으로 납득하기 어려운 변수나 데이터의 우연한 패턴에 의존했는지 확인하기 어렵다.

XAI는 블랙박스를 제거하거나 모델의 내부를 완전히 투명하게 만들지 않는다. 복잡한 모델의 행동을 사람이 해석할 수 있는 형태로 **근사하고 요약**한다. 따라서 XAI 결과는 모델 자체와 동일한 진실이 아니라, 특정 데이터·기준값·설명 방법에 의존하는 사후적 설명이다.

## 3. XAI 분석 전에 점검할 연구 설계

### 3.1 지도학습의 기본 단위

지도학습에서는 입력변수 X를 이용하여 결과변수 Y를 예측하는 함수 f를 학습한다.

$$
\hat{Y} = f(X)
$$

머신러닝의 feature는 사회과학의 독립변수와 비슷해 보이지만 완전히 같은 개념은 아니다. feature는 예측에 투입된 정보라는 뜻이며, 그 자체로 이론적 원인이나 처치변수를 의미하지 않는다. 마찬가지로 target은 예측 대상이지, 자동으로 인과분석의 종속변수가 되는 것은 아니다.

### 3.2 설명보다 성능 평가가 먼저다

예측하지 못하는 모델을 정교하게 설명해도 연구적 의미는 제한적이다. 기본 순서는 다음과 같아야 한다.

```text
연구 질문과 예측 대상 정의
→ 훈련 데이터와 테스트 데이터 분리
→ 훈련 데이터에서 모델 학습과 교차검증
→ 테스트 데이터에서 최종 성능 평가
→ 충분한 예측력을 확인한 뒤 XAI 분석
```

SHAP 그림을 먼저 출력하고 눈에 띄는 변수를 사후적으로 연구의 핵심 변수라고 선언해서는 안 된다. 모델의 성능과 타당성이 확인된 뒤에야 그 모델이 무엇을 학습했는지 설명할 수 있다.

### 3.3 설명 가능한 모델과 사후 설명

XAI는 크게 두 접근으로 나눌 수 있다.

- **본질적으로 해석 가능한 모델**: 선형회귀, 로지스틱 회귀, 작은 의사결정나무처럼 구조 자체를 읽을 수 있는 모델이다.
- **사후 설명 방법**: 복잡한 모델을 먼저 학습한 뒤 Feature Importance, PDP, SHAP, LIME, Permutation Importance 등을 적용하여 행동을 설명한다.

또한 설명의 범위도 구분해야 한다.

- **전역적 설명(Global explanation)**은 모델이 전체 자료에서 어떤 변수를 중요하게 사용하고 어떤 평균적 패턴을 학습했는지 묻는다.
- **국소적 설명(Local explanation)**은 특정 사례 하나의 예측이 왜 그렇게 나왔는지 묻는다.

## 4. Feature Importance, PDP, SHAP의 역할

세 방법은 같은 질문에 답하지 않는다.

| 방법 | 주요 질문 | 설명 범위 | 확인할 수 없는 것 |
| --- | --- | --- | --- |
| Feature Importance | 모델 전체에서 어떤 변수가 상대적으로 중요했는가? | 전역 | 효과의 방향, 구간 변화, 개별 사례의 이유 |
| PDP | 특정 변수 값이 달라질 때 평균 예측은 어떻게 변하는가? | 전역 | 개별 사례의 기여, 인과효과 |
| SHAP | 특정 예측이 기준 예측에서 벗어나는 데 각 변수가 얼마나 기여했는가? | 국소에서 전역으로 확장 | 통계적 유의성, 자동적인 인과효과 |

### 4.1 Feature Importance

트리 기반 모델의 `feature_importances_`는 분할 과정에서 각 변수가 불순도를 얼마나 줄였는지 종합한 모델 내부의 상대적 중요도다. 값이 크면 해당 모델이 학습 과정에서 그 변수를 많이 사용했다는 뜻이다. 값이 0이라고 해서 현실에서 그 변수가 중요하지 않거나 결과와 무관하다는 뜻은 아니다. 현재의 데이터와 학습된 모델에서 해당 중요도 기준으로 기여가 포착되지 않았다는 뜻이다.

`feature_importances_`는 모든 모델이 제공하지 않는다. 의사결정나무·랜덤포레스트·그래디언트 부스팅·ExtraTrees·XGBoost 계열에서 주로 제공되며, 구현에 따라 형식과 계산 기준이 다를 수 있다. 이 속성이 없는 모델에는 변수를 무작위로 섞었을 때 예측 성능이 얼마나 감소하는지 측정하는 Permutation Importance를 적용할 수 있다.

### 4.2 Partial Dependence Plot

PDP는 다른 변수들의 분포를 평균적으로 고려하면서 관심 변수의 값을 변화시켰을 때 모델의 평균 예측이 어떻게 달라지는지 보여준다. 선형모형이 놓칠 수 있는 임계점, 포화, 급격한 변화와 같은 비선형 패턴을 탐색하는 데 유용하다.

단일 의사결정나무의 예측 규칙은 구간별 분할로 구성되므로 PDP가 계단 모양으로 나타날 수 있다. 여러 나무를 결합한 앙상블 모델에서는 다수의 분할이 평균화되어 더 촘촘한 곡선이 나타날 수 있다. 그러나 PDP의 변화는 학습된 모델의 평균 예측 변화이며 현실의 개입 효과가 아니다.

### 4.3 SHAP

SHAP은 개별 예측값을 기준 예측값과 변수별 기여의 합으로 분해한다. 각 사례에서 계산한 SHAP 값을 모으면 모델 전체의 변수 중요도, 방향, 비선형성, 사례 간 이질성까지 탐색할 수 있다. 이 때문에 SHAP은 국소 설명에서 출발해 전역 설명으로 확장되는 방법이라고 할 수 있다.

## 5. SHAP의 게임이론적 원리

SHAP은 SHapley Additive exPlanations의 약자이며 게임이론의 Shapley value에서 출발한다. 공동의 성과를 참여자들의 기여에 따라 배분하는 문제를 머신러닝 예측에 대응시키면 다음과 같다.

| 게임이론 | 머신러닝 설명 |
| --- | --- |
| Player | Feature |
| Coalition | Feature의 조합 |
| Payout | 모델의 예측값 |
| Shapley value | Feature의 예측 기여도 |

특정 변수 i의 Shapley value는 그 변수가 여러 변수 조합에 추가될 때 예측값을 얼마나 변화시키는지 계산하고, 가능한 조합에 대해 가중평균한 값이다.

$$
\phi_i = \sum_{S \subseteq N \setminus \{i\}}
\frac{|S|!(M-|S|-1)!}{M!}
\left[v(S \cup \{i\})-v(S)\right]
$$

수식 전체를 외우기보다 다음 가법적 구조를 이해하는 것이 중요하다.

$$
f(x) = E[f(X)] + \sum_{j=1}^{p}\phi_j
$$

즉, 특정 사례의 예측값은 다음 요소로 분해된다.

```text
특정 사례의 예측값
= 기준 예측값(Baseline)
+ 변수 1의 기여
+ 변수 2의 기여
+ ...
+ 변수 p의 기여
```

Baseline은 보통 배경 데이터에서 모델이 내놓는 기대 예측값이다. 특정 사례의 SHAP 값이 양수이면 해당 변수의 현재 값이 모델 예측을 baseline보다 높이는 방향으로 기여했다는 뜻이고, 음수이면 낮추는 방향으로 기여했다는 뜻이다.

분류모델에서는 SHAP 값이 확률이 아니라 log-odds나 모델의 raw output 단위로 계산될 수 있다. 따라서 `+0.2`를 곧바로 `확률을 20%p 높였다`고 읽기 전에 explainer가 어떤 출력 척도를 설명하는지 확인해야 한다.

### 국소 설명을 전역 설명으로 바꾸는 방법

각 관측치마다 변수별 SHAP 값을 계산하면 한 사람, 한 문서, 한 지역의 예측을 설명할 수 있다. 전체 관측치에서 변수별 `|SHAP value|`의 평균을 구하면 전역적 SHAP 중요도가 된다. 절댓값 평균은 영향의 크기를 요약하지만 양의 방향과 음의 방향을 상쇄하지 않도록 만든 값이므로, 방향을 보려면 분포와 변수값을 함께 확인해야 한다.

## 6. 회귀계수와 SHAP을 혼동하지 않는 법

회귀계수와 SHAP 값은 서로 대체 관계가 아니다.

| 기준 | 회귀계수 | SHAP 값 |
| --- | --- | --- |
| 설명 대상 | 변수와 결과의 모형화된 관계 | 학습된 모델의 예측 |
| 기본 단위 | 모델 전체의 계수 | 관측치별 변수 기여도 |
| 대표 기호 | β | φ |
| 통계적 추론 | 표준오차·신뢰구간·p값을 사용할 수 있다 | 기본 SHAP에는 제공되지 않는다 |
| 비선형성 | 함수 형태를 지정해야 한다 | 설명 대상 모델이 학습한 비선형성을 반영한다 |
| 상호작용 | 교호작용항을 명시하는 경우가 많다 | 모델이 학습한 상호작용을 반영할 수 있다 |
| 주요 용도 | 평균적 관계와 추론 | 예측의 전역·국소 설명 |

회귀계수 `β_income = 2`는 모형과 가정에 따라 다른 조건이 동일할 때 소득이 한 단위 증가하면 Y가 평균적으로 두 단위 변하는 관계로 해석한다. 반면 한 사례에서 `φ_income = 0.8`이라는 결과는 그 사례의 현재 소득값이 모델 예측을 baseline에서 0.8만큼 이동시키는 데 기여했다는 뜻이다. 소득이 한 단위 증가할 때 Y가 0.8 증가한다는 뜻이 아니다.

SHAP 값은 같은 변수라도 사례마다 달라질 수 있다. 이 특성은 사회과학에서 이질성을 탐색하는 데 유용하다. 예를 들어 소득이 낮은 사례에서는 예측을 낮추고, 중간 소득에서는 크게 높이며, 높은 소득에서는 조금만 높이는 패턴이 나타날 수 있다. 이는 모델이 소득을 단순한 직선 관계로 사용하지 않았음을 보여준다.

그러나 SHAP이 회귀분석보다 발전된 방법이라는 뜻은 아니다. 평균적인 관계와 통계적 불확실성이 연구 질문이라면 회귀분석이 적합할 수 있다. 새로운 사례를 예측하는 것이 목적이라면 머신러닝이 유용할 수 있고, 그 예측을 사례별로 설명하려면 SHAP을 적용할 수 있다.

### 7.3 SHAP으로 예측 기여도 계산

트리 기반 XGBoost 모델을 `TreeExplainer`로 설명하고 테스트 데이터의 SHAP 값을 계산한다.

```python
# SHAP (Shapley Additive Explanations)
explainer = shap.TreeExplainer(xgb_model)

# 모델 자체가 아니라 테스트 데이터에 대한 예측 기여도를 계산한다.
shap_values = explainer.shap_values(X_test)

# 변수별 SHAP 중요도를 전역적으로 요약한다.
shap.summary_plot(
    shap_values,
    X_test,
    plot_type="bar",
    feature_names=X.columns
)
```

원문에 포함된 다음 이미지는 두 변수의 결합 기여를 배열한 SHAP interaction summary다.

![변수 쌍의 결합 기여를 보여주는 SHAP interaction summary](img/XAI3.png)

위의 `plot_type="bar"` 코드는 일반 SHAP 값을 변수별 막대로 요약하는 코드이고, interaction summary 이미지는 변수 쌍의 상호작용 값을 별도로 계산한 결과다. 트리 모델에서 이미지와 같은 상호작용 요약을 재현하려면 다음 과정이 추가로 필요하다.

```python
shap_interaction_values = explainer.shap_interaction_values(X_test)

shap.summary_plot(
    shap_interaction_values,
    X_test,
    feature_names=X.columns
)
```

interaction summary에서 각 행과 열은 변수 쌍을 나타내며, 가로축은 해당 변수 또는 변수 조합의 SHAP interaction value다. 0에서 멀리 퍼질수록 모델 예측에서 결합 기여의 절댓값이 크게 나타난 사례가 있다는 뜻이다. 일반적인 SHAP summary 색상에서 빨간색은 변수값이 높은 관측치, 파란색은 낮은 관측치를 뜻한다. 색은 효과의 긍정·부정을 직접 의미하지 않으며, 점의 좌우 위치가 예측을 높이거나 낮춘 방향을 나타낸다.

이 그림에서 복잡한 분포가 보인다고 해서 현실에서 두 변수가 인과적으로 상호작용한다고 결론 내릴 수는 없다. 학습된 모델이 두 변수의 조합을 예측에 사용했다는 사실을 보여줄 뿐이다.

## 8. 실제 연구 사례

### 8.1 조직·노동 연구의 이직 예측

조직 구성원의 이직 여부를 예측하는 모델을 만든 뒤 전역 SHAP으로 모델 전체에서 중요하게 사용한 요인을 확인할 수 있다. 이어서 국소 SHAP으로 특정 사례가 높은 이직 가능성으로 분류된 이유를 설명할 수 있다. 이때 설명 대상은 이직의 보편적 원인이 아니라 해당 모델의 예측 근거다.

### 8.2 도시·주거 연구의 임대료 예측

역세권 개발 요소와 지역 특성을 이용해 주거 임대료를 예측한 뒤 SHAP dependence plot으로 임계점과 비선형 패턴을 탐색할 수 있다. 개별 주택에 대한 국소 설명은 그 주택의 예측 임대료가 baseline보다 높거나 낮아진 데 어떤 특성이 기여했는지 보여준다. 모델이 학습한 변수 조합도 interaction value로 살펴볼 수 있다.

### 8.3 계산사회과학의 텍스트·진영 분류

리트윗 네트워크나 레이블을 이용하여 찬반 진영을 구분하고, 텍스트의 단어·토픽·어조를 feature로 학습할 수 있다. SHAP을 적용하면 특정 문서가 어느 진영으로 분류되는 데 어떤 단어나 토픽이 기여했는지 설명할 수 있다. 이를 통해 예측 성능만 보고 끝나는 것이 아니라 모델이 분류 기준으로 사용한 언어 패턴을 검토할 수 있다.

세 사례의 공통점은 SHAP을 독립적인 인과분석 도구로 사용하지 않는다는 점이다. 먼저 예측모델을 만들고 성능을 검증한 뒤, 그 모델이 전체 자료와 개별 사례에서 어떤 패턴을 사용했는지 해석한다.

## 9. 사회과학 연구자가 특히 주의할 점

### 9.1 SHAP 값은 인과효과가 아니다

양의 SHAP 값은 해당 변수의 현재 값이 모델 예측을 baseline보다 높였다는 뜻이다. 현실에서 그 변수를 개입하여 변화시키면 결과가 증가한다는 뜻이 아니다. 인과해석을 위해서는 시간적 선후관계, 교란 통제, 처치 할당, 식별 전략과 같은 별도의 연구설계가 필요하다. 회귀계수 역시 연구설계와 가정 없이 자동으로 인과효과가 되지 않는다.

### 9.2 상관된 변수는 기여도를 나누어 가질 수 있다

소득과 교육수준처럼 강하게 상관된 변수가 함께 들어가면 모델은 유사한 정보를 여러 변수에서 얻을 수 있다. 이때 SHAP 기여가 변수 사이에 분산되거나 설명 방식에 따라 달라질 수 있다. 따라서 높은 상관을 가진 변수는 이론적으로 구분되는지 검토하고, 변수 묶음과 대체 모형에 대한 민감도도 함께 살펴봐야 한다.

### 9.3 전역 중요도와 개별 사례를 혼동하지 않는다

전역 중요도가 높은 변수가 모든 사례에서 큰 영향을 미치는 것은 아니다. 반대로 전체 평균에서는 중요도가 낮더라도 특정 하위집단이나 사례에서는 결정적인 변수가 될 수 있다. 사회과학에서 SHAP의 장점은 이러한 사례 간 이질성을 탐색할 수 있다는 데 있다.

### 9.4 설명은 데이터와 모델에 조건부다

SHAP은 현실 전체가 아니라 특정 데이터로 학습된 특정 모델을 설명한다. 자료의 표본 구성, 측정 방식, 결측 처리, feature 설계, 알고리즘과 하이퍼파라미터가 바뀌면 설명도 바뀔 수 있다. 그러므로 결과를 보고할 때는 설명 대상 모델과 분석 데이터, baseline, 출력 척도, SHAP explainer를 명시해야 한다.

### 9.5 성능과 설명 가능성을 함께 보고한다

설명 그림만 제시해서는 모델이 신뢰할 만한지 알 수 없다. 최소한 다음 내용을 함께 보고해야 한다.

- 연구 질문과 예측 대상
- 표본과 feature의 구성 및 측정 방식
- 훈련·검증·테스트 데이터의 분리 방식
- 사용한 모델과 비교 기준
- 교차검증 및 테스트 성능
- 선택한 XAI 방법과 선택 이유
- 전역 설명과 국소 설명의 구분
- baseline과 모델 출력 척도
- 상관된 변수, 일반화, 인과해석에 관한 한계

## 10. 연구 질문에 따른 방법 선택

다음 세 질문으로 분석 방법을 결정할 수 있다.

1. **변수 간 평균적인 관계와 통계적 불확실성을 알고 싶은가?**  
   회귀분석을 비롯한 추론 모형이 우선이다.

2. **새로운 사례의 결과를 정확하게 예측하고 싶은가?**  
   훈련·검증·테스트 절차를 갖춘 머신러닝 모델이 유용하다.

3. **성능이 확인된 모델이 전체 자료 또는 특정 사례를 어떻게 판단했는지 알고 싶은가?**  
   Feature Importance, PDP, SHAP과 같은 XAI 방법을 적용한다.

한 연구에서 세 접근을 함께 사용할 수도 있다. 예를 들어 회귀분석으로 이론적 관계를 검토하고, 머신러닝으로 예측 가능성을 평가한 뒤, SHAP으로 예측모델이 포착한 비선형성과 사례별 이질성을 탐색할 수 있다. 다만 각 결과가 답하는 질문을 구분해서 보고해야 한다.

## 요약 및 최종 결론

XAI는 복잡한 인공지능 모델의 블랙박스를 완전히 제거하는 기술이 아니다. 모델의 행동을 사람이 검토할 수 있도록 근사하고 요약하는 분석 프레임워크다. 그중 Feature Importance는 모델 전체에서 변수의 상대적 중요도를, PDP는 변수 값의 구간에 따른 평균 예측 변화를, SHAP은 개별 예측이 baseline에서 달라지는 데 각 변수가 기여한 정도를 설명한다.

SHAP의 핵심은 `예측값 = 기준 예측값 + 변수별 기여의 합`이라는 가법적 구조다. 개별 사례마다 SHAP 값이 다르기 때문에 모델이 학습한 이질성과 비선형성을 탐색할 수 있고, 개별 설명을 모아 전역적 패턴도 정리할 수 있다. 그러나 SHAP 값의 크기와 부호는 학습된 모델의 예측 기여를 나타낼 뿐, 현실의 인과효과나 통계적 유의성을 의미하지 않는다.

인문사회연구자가 XAI와 SHAP을 사용할 때 가장 중요한 원칙은 설명보다 연구 질문과 모델 검증을 먼저 두는 것이다. 관계를 추론하려는 연구, 사례를 예측하려는 연구, 예측을 설명하려는 연구는 서로 다른 증거를 요구한다. 예측 성능이 확인되지 않은 모델의 설명은 의미가 약하며, 성능이 높은 모델이라도 데이터와 측정이 타당하지 않으면 해석할 수 없다.

결국 XAI의 연구적 가치는 모델이 정답을 말한다고 선언하는 데 있지 않다. 모델이 어떤 변수와 조합을 사용하여 예측했는지 드러내고, 그 패턴이 사회과학 이론과 자료 생성 과정에 비추어 타당한지 비판적으로 검토할 수 있게 하는 데 있다. SHAP은 회귀분석을 대체하는 더 우월한 방법이 아니라, 예측모델의 판단 구조와 사례 간 이질성을 탐색하기 위한 별도의 도구다. 이 구분을 지킬 때 XAI는 예측 성능과 사회과학적 해석 사이를 연결하는 유용한 방법론이 된다.
