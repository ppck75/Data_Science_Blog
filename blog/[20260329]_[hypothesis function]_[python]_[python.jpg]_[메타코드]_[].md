# conditional probability model과 hypothesis function에 대하여

---

## Conditional Probability Model에 대하여

### 1. 데이터의 출처: `P(X, Y)`와 i.i.d. 가정

우리가 가진 데이터셋은 세상의 모든 데이터가 아니라, **진짜 세상의 규칙(True Distribution, `P(X, Y)`)**에서 일부를 뽑아온 표본이다.

- `P(X, Y)`는 입력 `X`(예: 밈의 공유 수)와 정답 `Y`(예: 밈의 수명)가 동시에 발생하는 전체 확률 분포이다.
- i.i.d.(Independent and Identically Distributed)는 수집된 데이터가 서로 독립적이고, 동일한 확률 분포에서 나왔다는 가정이다.

예를 들어, 1번 밈의 유행이 2번 밈의 유행에 직접 영향을 주지 않고, 모두 유사한 인터넷 환경에서 생성되었다고 보는 관점이 i.i.d. 가정이다.

---

### 2. 핵심 목표: `P(Y|X)` 모델링

모델의 핵심 대상은 **`P(Y|X)`**이다. (Conditional Probability Model이)

- 의미: `X`라는 조건이 주어졌을 때 `Y`가 나타날 확률이다.
- 조건부 확률을 보는 이유: 지도학습은 `X`를 보고 `Y`를 예측하는 작업이기 때문이다.

예를 들어, "공유 수가 1,000건(`X`)일 때 수명이 30일(`Y`)일 확률"을 알고 싶은 것이 목적이다.

실제 정답 분포인 `P(Y|X)`는 직접 알 수 없으므로, 우리는 가설 함수 `h(x)`를 만들고 모델 출력이 실제 `P(Y|X)`의 기댓값과 최대한 가깝도록 학습시키는 방식으로 접근하는 것이다. 이떄, h(x)를 **hypothesis function**이라고 부른다.

---

### 3. 학습의 원리: 오차(Cost) 줄이기

학습의 핵심은 예측값과 실제값의 차이를 줄이는 과정이다.

1. 모델은 `h(x) = ?` 형태로 예측값을 출력한다.
2. 예측값 `?`와 실제값 `y`의 차이를 Cost(Loss) function으로 계산한다.
3. 이 차이가 작아질수록 모델 `h(x)`는 실제 법칙 `P(Y|X)`를 더 잘 설명하게 된다.

---

## Hypothesis Function 정리

### 개념

Hypothesis Function은 데이터 사이 관계를 설명하기 위한 모델의 수학적 제안이다.

사회과학적 가설인 "공부 시간이 늘어나면 성적이 오른다"를 `h(x) = wx + b` 같은 수식으로 표현하고, 데이터와 비교해 `w`, `b`를 조정해 가는 과정이 모델 학습이다.

---

### 수식 관점

- `h(x)`를 통해 새로운 입력 `x`에 대한 예측값 `?`를 계산하는 구조이다.
- 이때 모델은 `h(x)`가 `P(Y|X)`를 근사한다고 가정한다.
- 즉, `h(x)`는 관측 불가능한 조건부 분포 `P(Y|X)`를 추정하기 위한 실용적 함수이다.

---

## 사회과학 데이터 분석으로 비유

회귀분석과 동일한 논리로 이해할 수 있다.

- 세상의 법칙: 교육 수준 `X`가 높을수록 소득 `Y`가 높아지는 확률적 경향 `P(Y|X)`가 존재한다.
- 모델링: `h(x) = wx + b` 형태의 가설 함수를 세운다.
- 예측: 새로운 개인의 교육 수준을 넣어 예상 소득 `?`를 계산한다.
- 평가: 실제 소득 `y`와 비교해 가설의 설명력을 검증한다.

---

## i.i.d. 가정이 깨지는 경우

iid 가정이 깨지는 경우는 언제가 있을까?

예를 들어, 가상 아이돌 팬덤 트윗 데이터를 수집할 때 한 사용자가 수천 개의 트윗을 작성했다면, 그 트윗들은 서로 독립이라고 보기 어렵다. 이는 i.i.d. 가정 위배 가능성을 의미하며, 분석 단계에서 표본 구성과 모델 해석에 주의가 필요하다는 신호이다.
