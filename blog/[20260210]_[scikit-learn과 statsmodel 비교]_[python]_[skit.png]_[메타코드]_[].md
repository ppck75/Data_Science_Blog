# Scikit-learn과 statsmodel의 선형 회귀와 통계 모델의 차이점

간단히 요약하자면,

1. scikit-learn의 LinearRegression
- 되게 간단하다. 모델 만들 때 주로 사용한다(모델 돌려보고 결과만 볼 때)
- 주로 예측을 위한 모델링에 사용한다. 
- 머신러닝 워크플로우(데이터 전처리, 모델 선택, 하이퍼파라미터 튜닝 등)와 통합하기 좋다. 
- 간결하고 사용하기 쉬운 API를 제공한다. 
- 단, 통계적 검정이나 모델 요약 시각화 표를 제공하지 않는다(회귀계수는 볼 수 있지만, p-value는 제공되지 않는다.)
*p-value를 보려면 statsmodels를 쓰거나, sklearn 결과를 통계적으로 다시 평가해야 한다.*

2. statsmodels의 OLS
- 회귀모형에 대해서 깊게 보고 싶을 때 사용한다(통계적 검정 결과를 볼 때 )
- 주로 '통계 분'석 및 '모델 해석'에 사용하는 라이브러리이다. 
- 상세한 모델 요약과 통계적 검정(예: p-value, t-value, F, R2, 각각의 coef)을 제공한다. 
- 회귀 진단 플롯과 같은 시각화 기능을 포함한다. 
- pandas의 DataFrame를 선호하낟. 


물론, 둘 다 사용 가능하며 호환이 가능해서 같이 쓸 수 있다.

예를 들어, scikit-learn을 사용하여 모델을 학습하고 평가한 후, statsmodels를 사용하여 모델의 통계적 검정을 수행할 수 있다!

*Haree Srinivasan의 Linear Regression in Scikit-learn vs Statsmodels 포스팅 정리*

파이썬으로 선형 모델을 만들려는 사람들은 선택지가 많아질 것이다. 가장 인기 있는 선형 모델 라이브러리 두 가지는 scikit-learn의 linear_model와 statsmodels.api이다. 

 두 라이브러리 모두 선형 모델을 성공적으로 적합하고 예측을 계산할 수 있지만, 여러 면에서 차이가 있어 반드시 같은 목적을 위한 수단은 아니다. 일반적으로 scikit-learn은 예측용으로 설계된 반면, statsmodels는 설명 분석에 더 적합하다.


#### 상수처리 방식

두 라이브러리의 주요 차이점은 상수 처리 방식이다. Scikit-learn은 사용자가 매개변수를 통해 상수를 추가할지 여부를 지정할 수 있게 하며, statsmodels의 OLS 클래스는 주어진 배열에 상수를 추가하는 함수를 가지고 있다

...

결국 저자는 scikit-learn이 일반 최소제곱 회귀를 적합시키는 데 statsmodels보다 더 빠르다는 결론을 내렸다. 

#### 시각화

statsmodel의 OLS 클래스를 통해 회귀분석의 요약표를 쉽게 얻을 수 있으며, 모델 적합 후 필요한 함수를 호출할 수 있다. (p값, F통계량, R2, adj R2, coef와 그에 따른 여러 테이블들.. 우리가 익숙한 그 테이블!)

많은 정보는 scikit-learn의 LinearRegression 클래스를 통해 얻을 수 있지만, 테스트 통계와 정보 기준 지표 등 속성으로 쉽게 얻을 수 있는 정보는 아니며, scikit-learn은 유사한 시각화를 제공하지 않는다. 

왜? -> 약표는 모델 설명에 유용하지만, 예측 목적상 불필요한 정보를 연결한다.  scikit-learn의 라이브러리가 예측을 위해 설계되었기 때문에, 이러한 요약표는 필요하지 않는다. 


#### 로지스틱 회귀 

선형 회귀를 이용해 확률을 예측하려는 사람들은 종종 OLS의 악마인 로지스틱 회귀를 사용한다. 다행히도 scikit-learn과 statsmodel 모두 로지스틱 회귀 기능을 제공한다. 하지만 기본 매개변수만 적용해 두 모델을 실행하면 결과가 다르다. 어떻게 이럴 수 있지?

답은 정규화!!; scikit-learn은 기본적으로 로지스틱 회귀를 정규화한다. 정규화는 예측 시 학습 데이터에 대한 모델의 과적합을 방지하는 데 도움이 된다. 따라서 scikit-learn의 적절한 기본값이다.  이 매개변수 C는 높은 값으로 설정하면 효과적으로 끌 수 있다. Statsmodels에는 로지스틱 회귀를 정규화하는 fit_regularized()라는 기능이 있다.

Statsmodels는 알고리즘 선택지가 더 많지만, scikit-learn은 statmodels가 제공하지 않는 일부 옵션을 허용한다 

일반적으로 scikit-learn의 선형 모델, 예를 들어 능선 회귀와 라쏘 회귀는 정규화와 예측에 적합하다. 이 검사들은 모델이 과도하게 학습되는 것을 방지하여 궁극적으로 더 정확한 예측을 제공하기 위해 설계되었다. Scikit-learn에는 예측 지표 계산과 교차 검증 지표 계산을 돕는 다른 모듈도 있는데, 두 가지 모두 예측에 유용한 도구이다. 반면, 통계모델에서 제공하는 선형 모델은 OLS의 기본 가정이 깨졌을 때 구현되도록 설계되었다. 예를 들어, 가중 최소제곱법(WLS)은 이질성 보정에 도움을 준다. 이 모델들은 엄격한 통계를 수행할 때 유용하다.

### 정리

주요 차이점을 요약하자면:

· OLS 효율성: scikit-learn은 선형 회귀에서 더 빠릅니다; 이 차이는 더 큰 데이터셋에서 더 뚜렷하게 나타납니다

· 로지스틱 회귀 효율: 단일 코어만 사용하는 통계 모델이 로지스틱 회귀에서 더 빠릅니다

· 시각화: statsmodels가 요약 표를 제공합니다

· 해석기/방법: 일반적으로 statsmodels는 더 다양한 형태를 제공합니다

· 로지스틱 회귀: scikit-learn은 기본적으로 정규화하지만 statsmodels는 그렇지 않습니다

· 추가 선형 모델: scikit-learn은 정규화를 위한 더 많은 모델을 제공하며, statsmodels는 깨진 OLS 가정을 보정하는 데 도움을 줍니다!!

---

일반적으로 scikit-learn은 기계 학습을 위해 설계된 반면, statsmodels는 엄격한 통계를 위해 만들어졌습니다. 두 라이브러리 모두 각자의 용도가 있습니다. 어느 쪽을 선택하기 전에 모델의 목적을 고려하는 것이 가장 좋습니다. 예측을 위해 설계된 모델은 scikit-learn을 사용하는 것이 가장 적합하며, statsmodels는 설명 모델에 가장 적합합니다.
