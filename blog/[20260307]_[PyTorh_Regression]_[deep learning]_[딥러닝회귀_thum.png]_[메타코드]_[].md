# 딥러닝의 이해: PyTorch Regression Model

PyTorch로 회귀(Regression) 문제를 다루는 기본 흐름을 정리한다.  
이번 내용은 **회귀의 개념**, **선형 회귀 모델**, 그리고 **FC Layer 기반 신경망 회귀 모델**을 비교하며 이해하는 데 초점을 둔다.

---

## 1. 회귀(Regression)란?

회귀는 입력 \(x\)로부터 연속형 출력 \(y\)를 예측하는 문제다.
즉, 분류처럼 클래스를 맞히는 것이 아니라 **숫자 값 자체**를 예측한다.

> 핵심: 입력(Feature)과 출력(Label) 사이의 관계를 학습해, 새로운 입력의 수치형 타깃을 예측한다.




### 1.1. 데이터 분할과 평가

일반적으로 데이터를 train/test로 분할한다(예: 7:3 또는 8:2).  
모델은 train set으로 학습하고, test set으로 일반화 성능을 확인한다.

회귀 성능 평가지표로는 RMSE를 자주 사용한다.

**핵심 식**

\[
RMSE = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2}
\]

---

## 2. 선형 회귀 (Linear Regression)

가장 기본적인 회귀 모델은 선형 회귀다.

**핵심 식**

\[
\hat{y} = Wx + b
\]

- \(x\): 입력 벡터(Feature)
- \(W\): 가중치
- \(b\): 편향(Bias)

선형 회귀는 해석이 쉽고 빠르지만, 입력-출력 관계가 복잡하게 비선형일 때는 한계가 있다.

<br>

### 2.1. 더미 변수와 입력 표현

`CHAS`처럼 0/1 값으로 표현되는 변수는 모델 입력에 그대로 쓰거나, 상황에 따라 원-핫 인코딩 형태로 확장해 사용할 수 있다.  
회귀 모델에서 중요한 건 **모든 입력을 수치형 텐서로 일관되게 구성**하는 것이다.

---

## 3. FC Layer 기반 회귀 신경망

선형 회귀를 확장해, FC Layer(완전연결층)를 여러 개 쌓은 신경망으로 회귀를 수행할 수 있다.

예시 구조:
- `FC(13, 6)` -> `ReLU` -> `FC(6, 1)`

이 구조는 선형 회귀보다 표현력이 높아, 더 복잡한 패턴을 학습할 수 있다.

<br>

### 3.1. 파라미터 수 비교

**보조 식(인라인)**

- 선형 회귀(13입력, 1출력):
  - 파라미터 \(= 13 + 1 = 14\)
- 2층 FC 신경망 `13->6->1`:
  - 파라미터 \(= (13\times6 + 6) + (6\times1 + 1) = 91\)

즉, 신경망은 파라미터가 많아져 학습 유연성은 커지지만, 과적합 관리와 학습 안정성이 더 중요해진다.

<br>

### 3.2. 학습 방식

PyTorch에서는 보통 다음 흐름으로 학습한다.

1. `torch.utils.data`로 Dataset/DataLoader 구성
2. 손실함수 정의(예: `nn.MSELoss`)
3. 옵티마이저 정의(예: `Adam`)
4. 미니배치 학습 반복(Forward -> Loss -> Backward -> Step)

선형 회귀의 폐형해(최소제곱) 접근과 달리, 신경망은 주로 경사하강 기반 최적화를 사용한다.

---

**결론**:  
PyTorch 회귀 모델의 핵심은  
1) 회귀 문제를 입력/출력 관점으로 명확히 정의하고,  
2) 선형 회귀를 기준점으로 삼은 뒤,  
3) 필요할 때 FC Layer 기반 신경망으로 확장하는 것이다.

결국 모델 선택은 **데이터 복잡도**, **해석 가능성**, **성능 요구 수준** 사이의 균형 문제다.

<br>

## 4. 고전적 회귀 vs 딥러닝 회귀 모델 비교

| 비교 항목 | 고전적 회귀(Linear Regression 등) | 딥러닝 회귀(FC Layer 기반) |
|---|---|---|
| 모델 구조 | 단일/얕은 선형 구조 | 다층 비선형 구조 |
| 표현력 | 선형 관계에 강함 | 복잡한 비선형 관계 학습 가능 |
| 해석 가능성 | 높음(계수 해석 용이) | 상대적으로 낮음(블랙박스 성향) |
| 파라미터 수 | 적음 (예: 14) | 많음 (예: 91) |
| 학습 방식 | 최소제곱해, 비교적 단순 최적화 | 경사하강 기반 반복학습(Adam 등) |
| 데이터 요구량 | 비교적 적은 데이터에서도 안정적 | 일반적으로 더 많은 데이터에서 강점 |
| 과적합 위험 | 상대적으로 낮음 | 상대적으로 높아 정규화/검증 필요 |
| 계산 비용 | 낮음, 빠름 | 상대적으로 큼 |
| 추천 상황 | 빠른 베이스라인, 해석 중심 분석 | 예측 성능 중심, 패턴 복잡한 문제 |
