# 3 클러스터링
문장→ SBERT → 벡터(의미좌표) → K-means → 군집(주제/프레임) (데이터마이닝 과정)

SBERT도 그 모델이 가진 토크나이저(wordpiece기반)와 vocab에 따라 문장을 토큰화하고 벡터화한다. 
K-means 클러스터링  군집갯수 k 설정 -> k개의 랜덤 센트로이드 설정 -> 최근접 할당(각 데이터를 가장 가까운 중심에 배정) -> 중심 재계산(각 클러스터의 평균 벡터로 센트로이드 갱신) -> 수렴까지 반복(변화없을 떄까지 또는 하이퍼파라미터에 따라) / 여기서 목표함수는 클러스터내 거리 최소화하는 함수로 설정(거리는 코사인 유사도 또는 유클리디안거리)  / k 값 선택: Elbow Method(SSE 계산, SSE 급격히 감소하다 완만해지는 구간이 적정), 실루엣 스코어(각 데이터 포인트의 소속 적합도를 측정한다 -1~1. k별 평균 실루엣스코어가 가장 높은 값을 선택한다)

의미 기반 군집의 결과 해석: kmeans는 라벨을 자동으로 부여하지 않기 떄문에 주제, 이슈, 담론 등으로 클러스터를 해석해야 한다.  

SBERT + K-means -> 의미 공간에서 자연스럽게 형성된 구조를 발견할 수 있다. 단, normalize → K-means → 사람이 해석해야 한다. (정규화가 필수이다. SBERT임베딩은 코사인 유사도 기반이고 kmeans는 유클리드거리기반)
