# 시험대비 한 장 정리(중간고사 범위)

인공지능미디어코딩 리뷰용 핵심 개념 정리이다. 흐름은 `임베딩 -> 토큰화 -> 클러스터링 -> 딥러닝 기초 -> RNN/CNN -> Transformer -> BERT` 순서이다. 

---

## 1. 임베딩 벡터와 유사도

문장을 벡터화하는 대표 방법은 `원핫인코딩`, `TF-IDF`, `임베딩(밀집벡터)`이다.

- `원핫인코딩`: 단어사전 크기만큼 차원을 가지며, 한 위치만 1이고 나머지는 0이다. 의미적 유사성을 반영하지 못한다.
- `TF-IDF`: 빈도와 희소성을 반영해 원핫보다 중요도를 더 잘 표현하지만, 여전히 희소벡터이고 의미 유사성 표현은 제한적이다.
- `임베딩`: 단어를 낮은 차원의 밀집벡터로 표현한다. 비슷한 맥락에서 쓰이는 단어는 비슷한 벡터를 갖는다.

### 임베딩 행렬

- 예를 들어 원핫 차원이 1000이라면, 임베딩 행렬은 `(1000, 768)`처럼 만들 수 있다.
- 원핫벡터에서 1이 있는 위치의 행을 임베딩 행렬에서 꺼내는 방식이 `룩업(lookup)`이다.
- 차원은 줄이면서 의미 정보는 보존하려는 것이 핵심이다.

### 임베딩 학습

1. 대량 텍스트를 수집한다.
2. 주변 단어 예측 같은 과제로 의미를 학습한다.
3. 예측이 틀리면 가중치를 수정한다.
4. 반복하면서 임베딩 행렬에 의미 관계가 반영된다.

`word2vec`은 이런 방식의 대표 예시다.

### 멀티모달 임베딩

- 이미지, 음성, 영상도 벡터로 바꿀 수 있다.
- `CLIP`처럼 텍스트와 이미지를 같은 벡터 공간에 배치하면 텍스트-이미지 검색이 가능하다.

### 코사인 유사도

- 벡터의 길이보다 `방향`을 비교한다.
- 각도가 작을수록 의미가 비슷하고, 코사인 유사도 값이 클수록 유사하다.
- 최근 문장 임베딩은 `SBERT`를 많이 사용하며, 코사인 유사도로 문장 유사도를 바로 계산한다.

## 2. 토큰과 토크나이징

`토큰화(tokenization)`는 텍스트를 모델이 처리할 수 있는 작은 단위로 쪼개는 과정이다.

### 전통 NLP vs LLM

- 전통 NLP: 토큰화, 정제, 형태소 분석, 표제어 추출, 불용어 제거, 인코딩, 패딩 등 전처리가 많다.
- LLM 기반 NLP: `텍스트 -> 토크나이저 -> token ids -> 모델 입력` 흐름이며, 전처리를 크게 줄인다.

### 핵심 차이

- 전통 NLP는 단어/형태소 기반 토큰을 많이 쓴다.
- LLM은 주로 `subword` 기반 토큰을 사용한다.
- 모델마다 자기만의 `tokenizer`와 `vocabulary(vocab)`를 가진다.
- 같은 문장도 모델마다 다르게 쪼개질 수 있다.

### subword 토크나이징 방식

- `BPE`: 자주 같이 나오는 글자 쌍을 병합한다.
- `WordPiece`: 병합 후보 중 확률적으로 가장 좋은 쌍을 선택한다.
- `SentencePiece`: 공백까지 포함한 전체 문자열 기준으로 학습한다.

공통점은 단어를 더 작은 subword 단위로 나눠 `OOV(사전에 없는 단어)` 문제를 줄이고, vocab 크기를 통제한다는 점이다.

### 왜 vocab가 중요한가

- vocab에 어떤 토큰이 들어 있는지가 모델 성능에 직접 영향을 준다.
- 한국어를 잘하는 모델은 한국어 subword가 충분히 잘 설계돼 있을 가능성이 높다.
- 결국 토크나이저는 단순 전처리가 아니라, 언어를 어떻게 분해하고 인식할지에 대한 설계 철학이다.

## 3. 클러스터링

흐름은 보통 다음과 같다.

`문장 -> SBERT -> 임베딩 벡터 -> K-means -> 군집`

### SBERT + K-means

- `SBERT`는 문장을 의미 기반 벡터로 변환한다.
- `K-means`는 벡터들을 비슷한 것끼리 묶는다.
- 결과적으로 주제, 프레임, 담론 같은 구조를 찾을 수 있다.

### K-means 절차

1. 군집 수 `k`를 정한다.
2. `k`개의 초기 중심점(centroid)을 둔다.
3. 각 데이터를 가장 가까운 중심에 할당한다.
4. 각 군집의 평균으로 중심을 다시 계산한다.
5. 더 이상 변화가 없을 때까지 반복한다.

### k 선택 방법

- `Elbow Method`: SSE가 급격히 줄다가 완만해지는 지점을 찾는다.
- `Silhouette Score`: 군집 적합도를 수치화해 평균 점수가 높은 k를 선택한다.

### 해석 시 주의점

- K-means는 군집을 나눠주지만, 군집의 `의미 라벨`은 자동으로 붙여주지 않는다.
- 사람이 결과를 보고 주제나 프레임으로 해석해야 한다.
- SBERT는 코사인 유사도 기반이고, K-means는 유클리드 거리 기반이므로 보통 `정규화(normalize)` 후 적용하는 것이 중요하다.

## 4. 딥러닝 기본 개념

### 퍼셉트론과 신경망

- `퍼셉트론`은 초기 인공신경망 모델이다.
- 입력값과 가중치를 합한 뒤 편향을 더해 선형 결합을 만들고, 활성화 함수를 통과시켜 출력을 만든다.

수식 형태:

`z = w1x1 + w2x2 + b`

`y = f(z)`

- 단층 퍼셉트론은 `XOR` 문제를 해결하지 못한다.
- 이를 해결하기 위해 `MLP(다층 퍼셉트론)`가 등장했다.
- 은닉층이 깊어지면 `DNN`, 이를 학습하는 것이 `딥러닝`이다.

### 활성화 함수

- `시그모이드`: 이진 분류 출력층에 자주 사용되지만, 기울기 소실 문제를 유발하기 쉽다.
- `소프트맥스`: 다중 클래스 분류 출력층에 사용한다.
- `ReLU`: 은닉층에서 많이 쓰며 기울기 소실을 완화한다.

### 네트워크 구조

- `FFNN`: 입력층 -> 은닉층 -> 출력층으로 순방향만 진행한다.
- `전결합층(밀집층)`: 한 층의 모든 뉴런이 다음 층의 모든 뉴런과 연결된다.
- 은닉층은 특징을 추출하는 역할을 한다.

### 학습 방식

- `지도학습`: 입력과 정답(label)을 함께 사용한다.
- `비지도학습`: 정답 없이 데이터 구조를 학습한다.
- `자기지도학습`: 데이터 자체에서 정답 신호를 만든다.
- `강화학습`: 환경과 상호작용하며 보상을 최대화한다.

### 학습 단위

- `배치 크기`: 한 번에 모델에 넣는 데이터 수
- `이터레이션`: 한 번의 배치 처리와 가중치 업데이트
- `에포크`: 전체 데이터를 한 번 다 학습하는 것

### 역전파와 옵티마이저

- `역전파`는 출력층에서 입력층 방향으로 오차를 전파하며 가중치와 편향을 업데이트하는 과정이다.
- `학습률`은 한 번에 얼마나 이동할지 결정한다.
- `옵티마이저`는 손실함수를 줄이도록 가중치를 조정한다.

대표 흐름:

`모델 초기화 -> 순전파 -> 손실 계산 -> 역전파 -> 가중치 업데이트 -> 반복`

### 기울기 소실과 폭주

- `기울기 소실`: 앞쪽 층으로 갈수록 그래디언트가 거의 0이 되어 학습이 잘 안 되는 문제
- `기울기 폭주`: 그래디언트가 너무 커져 학습이 불안정해지는 문제

해결 방법:

- ReLU 계열 사용
- 잔차 연결
- 배치 정규화 / 레이어 정규화
- 적절한 가중치 초기화
- 그래디언트 클리핑

### 과적합

- 학습 데이터의 노이즈까지 외워 일반화가 안 되는 상태다.

해결 방법:

- 데이터 증가 및 데이터 증강
- 드롭아웃
- Early Stopping
- L1/L2 규제

### 평가 지표

- `정확도`: 전체 중 맞춘 비율
- `정밀도`: 양성이라고 예측한 것 중 실제 양성 비율
- `재현율`: 실제 양성 중 찾아낸 비율
- `F1 score`: 정밀도와 재현율의 조화평균

정밀도는 `틀린 양성 판정`이 치명적일 때 중요하고, 재현율은 `놓치는 것`이 치명적일 때 중요하다.

## 5. RNN과 CNN

## 5-1. RNN

- 일반 `FFNN`은 입력 순서를 고려하지 못한다.
- 시퀀스 데이터는 순서가 중요하므로 `RNN`이 등장했다.
- RNN은 이전 시점의 은닉 상태를 다음 시점으로 넘기며 정보를 기억한다.

### RNN 한계

- 시간 방향 역전파에서 기울기 소실이 심하다.
- 시퀀스가 길어질수록 앞의 정보가 뒤에 잘 전달되지 않는 `장기 의존성 문제`가 생긴다.

### 보완 구조

- `Deep RNN`
- `BiRNN`
- `LSTM`
- `GRU`

### 활용 형태

- `1 to M`: 이미지 캡셔닝
- `M to 1`: 감정분석, 텍스트 분류
- `M to M`: 품사 태깅, 개체명 인식, 기계번역, 요약

### seq2seq와 Attention

- `seq2seq`는 인코더가 입력을 고정 길이 벡터로 압축하고, 디코더가 이를 바탕으로 출력 시퀀스를 생성한다.
- 하지만 긴 문장을 하나의 벡터에 압축하면 `병목현상`과 정보 손실이 생긴다.
- 이를 해결하기 위해 `Attention`이 도입됐고, 결국 Transformer로 발전했다.

## 5-2. CNN

- 이미지 데이터는 보통 `(높이, 너비, 채널)` 형태의 3차원 텐서다.
- 일반 신경망으로 이미지를 처리하면 파라미터 수가 너무 많고, 픽셀의 공간적 관계가 무시된다.
- `CNN`은 합성곱을 통해 지역 특징을 추출하고 공간 구조를 유지한다.

### 핵심 요소

- `커널(필터)`: 이미지 위를 이동하며 특징을 추출하는 가중치
- `합성곱`: 겹치는 부분끼리 곱해서 더하는 연산
- `특성맵(feature map)`: 필터를 통과한 결과
- `스트라이드`: 필터 이동 간격
- `패딩`: 가장자리를 0 등으로 채워 출력 크기를 조절

### CNN 구조

`입력 -> 합성곱 + ReLU -> 풀링 -> 합성곱 + 풀링 반복 -> Flatten -> FC Layer -> Softmax`

- `풀링`은 중요한 특징은 유지하면서 크기를 줄인다.
- 깊은 층으로 갈수록 더 복잡한 고수준 특징을 학습한다.

### 활용 분야

- 이미지 분류
- 객체 탐지
- 이미지 세분화
- 뉴스 영상 프레이밍, 소셜 미디어 이미지 분석 등 미디어 연구

### YOLO

- `YOLO`는 이미지를 한 번만 보고 객체의 위치와 종류를 동시에 예측하는 실시간 객체 탐지 모델이다.
- 자율주행, CCTV, 의료 영상 등에서 활용된다.

### ViT

- `ViT(Vision Transformer)`는 CNN 없이 이미지를 패치 단위로 나누고, 이를 토큰처럼 처리해 Transformer에 넣는다.
- 이미지 처리에서도 Transformer가 강력함을 보여준다.

### RNN vs CNN

- RNN은 시간 순서 정보를 다룬다.
- CNN은 공간 패턴을 잘 다룬다.
- 둘 다 중요한 구조였지만, 최근 많은 영역에서 Transformer 계열이 대체하고 있다.

## 6. Transformer

Transformer는 `RNN/LSTM`의 느린 순차 처리와 장기 의존성 문제를 해결하기 위해 등장했다.

### 핵심 아이디어

- 모든 단어 사이의 관계를 한 번에 계산하는 `Self-Attention`
- 순차 처리 없이 가능한 `병렬 처리`
- 멀리 떨어진 단어 사이 관계도 직접 계산 가능

### 기본 구조

- `인코더`: 입력 시퀀스를 문맥화된 표현으로 바꾼다.
- `디코더`: 인코더 출력을 참고해 출력 시퀀스를 생성한다.

### 입력 구성

- `입력 임베딩`
- `위치 인코딩`

Transformer는 순서를 자체적으로 알 수 없으므로 위치 정보를 별도로 더해줘야 한다.

### Q, K, V

각 단어 벡터에서 다음 세 벡터를 만든다.

- `Q(Query)`
- `K(Key)`
- `V(Value)`

과정:

1. 한 단어의 Q와 모든 단어의 K를 내적해 관련성 점수를 구한다.
2. 점수를 `sqrt(dk)`로 나눠 스케일링한다.
3. `softmax`로 확률 분포로 바꾼다.
4. 그 가중치로 V들을 합쳐 새로운 문맥 벡터를 만든다.

즉, attention은 "어떤 단어를 얼마나 중요하게 볼 것인가"를 계산하는 메커니즘이다.

### Self-Attention vs Cross-Attention

- `Self-Attention`: Q, K, V가 모두 같은 시퀀스에서 온다.
- `Encoder-Decoder Attention(Cross-Attention)`: Q는 디코더, K/V는 인코더에서 온다.

### 멀티헤드 어텐션

- 한 가지 관계만 보는 대신 여러 관점에서 동시에 attention을 수행한다.
- 각 헤드가 서로 다른 관계 패턴을 학습하고, 마지막에 합쳐서 더 풍부한 표현을 만든다.

### 인코더 블록

1. 멀티헤드 셀프어텐션
2. Add & Norm
3. Position-wise FFNN
4. Add & Norm

잔차 연결과 정규화는 학습 안정성과 정보 보존에 중요하다.

### 디코더 블록

1. 출력 임베딩 + 위치 인코딩
2. Masked Self-Attention
3. Add & Norm
4. Encoder-Decoder Attention
5. Add & Norm
6. FFNN
7. Add & Norm

`Masked Attention`은 미래 단어를 미리 보지 못하게 막아 자기회귀 생성이 가능하도록 한다.

## 7. BERT와 SBERT

### BERT

`BERT`의 핵심은 `양방향 문맥 이해`다. 즉, 왼쪽과 오른쪽 문맥을 함께 본다.

- `BERT-base`: 12개 인코더 층, 768차원 임베딩, 12개 어텐션 헤드
- `BERT-large`: 더 깊고 크며 파라미터 수가 훨씬 많다

### 입력 구성

- 최대 길이: 512 토큰
- 두 문장까지 입력 가능
- 특수 토큰:
  - `CLS`: 문장 시작, 분류용
  - `SEP`: 문장 구분 및 종료

BERT 입력은 다음 세 임베딩의 합으로 구성된다.

- 토큰 임베딩
- 세그먼트 임베딩
- 위치 임베딩

### 사전학습

1. `MLM(Masked Language Modeling)`: 가린 단어를 예측한다.
2. `NSP(Next Sentence Prediction)`: 두 문장이 실제로 이어지는지 판단한다.

### 파인튜닝

사전학습된 BERT를 특정 작업 데이터에 맞게 다시 학습시킨다.

활용 예:

- 문장 분류
- 개체명 인식(NER)
- 자연어 추론
- 질의응답

### BERT vs SBERT

- `BERT`: 각 토큰별 벡터를 잘 만들고, 두 문장을 비교하려면 함께 넣고 다시 추론해야 해서 느리다.
- `SBERT`: 문장 전체를 하나의 벡터로 만들고, 문장끼리 코사인 유사도로 빠르게 비교할 수 있다.

즉:

- BERT는 `단어 수준 문맥 이해`에 강하다.
- SBERT는 `문장 수준 의미 비교`에 강하다.

## 마지막 포인트

- 임베딩은 `희소표현 -> 밀집표현`으로 가며 의미 유사성을 담는다.
- LLM 시대 핵심은 `subword 토크나이저 + vocab`이다.
- 문장 분석 파이프라인에서 `SBERT + K-means`는 의미 기반 군집화의 대표 조합이다.
- 딥러닝의 핵심 학습 메커니즘은 `순전파 -> 손실 -> 역전파 -> 옵티마이저 업데이트`다.
- RNN은 순차 데이터에 강하지만 장기 의존성과 병렬 처리 한계가 있다.
- CNN은 이미지의 공간 구조를 보존하며 특징을 추출한다.
- Transformer는 self-attention으로 긴 거리 관계와 병렬 처리를 해결했다.
- BERT는 양방향 이해, SBERT는 문장 임베딩 비교에 강점이 있다.
