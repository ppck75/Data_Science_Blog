# BERT
핵심: 양방향문맥 이해(좌→우, 우→좌 양쪽 즉, 앞뒤문맥을동시에활용. GPt는 단방향으로 텍스트를 생성하는 모델) / BERT-base: 인코더층수12,임베딩차원768,셀프어텐션헤드수 12 / BERT-larg는 L,D,A 모두 늘림. 파라미터도 훨씬 많음
BERT의 입력구성: 최대시퀀스길이:512토큰, 두 문장까지 입력가능, 특구토큰 CLS(문장시작, 분류용), SEP 문장구분과 끝. BERT 입력으로 3가지 임베딩의 합이 들어간다(토큰 임베딩+세그먼트임베딩+위치 임베딩) / wordPiece 토크나이징(확률기반 서브워드 방식 분리. 자주 등장하는 단어 그대로 유지하고 드문단어는 서브워드로>OOV 문제 해결)
BERT 사전학습(1):MLM(토큰단위에서 서로 잘이해하나?)-입력단어의15%를 무작위 선택하여 가려진 단어 예측하도록 학습 / (2)NSP(시퀀스 단위)-QA,자연어 추론 등에 활용한다. 실제 연속 문장 라벨 ISnext, 무작위 문장 라벨 NotNext.
파인튜닝(전이학습): 지도학습이다.사전학습된 BERT를 가져와 맞춤형 데이터로 파라미터 정교, 세밀하게 재조정. 1. 한 문장의 성격 분류(CLS토큰을 본다) 2.단어태깅NER(개체명이나 품사 분석) 3. 자연어추론(문장간관계 분석, CLS토큰 본다.NSP이용) 4. 질의응답(새로운 내용 생성,NSP이용)

SBERT: BERT가 단어 수준 이해라면, SBERT는 문장 수준 비교이다.
BERT: 출력-각 단어마다 768차원 벡터1개(문장전체대표벡터X)(CLS를 보고 파악했음), 두 문장을 반드시 함께 입력, 많은시간소요(매번 추론해야함) / SBERT: 단어벡터를 풀링으로 요약해서 문장 전체를 벡터한개로 출력. 각문장을 독립적으로 인코딩한 후 코사인 유사도로 즉시 비교, 매우 빠름(벡터 연산만 하면 되니까)
