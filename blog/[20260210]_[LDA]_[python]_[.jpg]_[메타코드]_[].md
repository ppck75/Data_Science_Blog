# LDA(선형판별분석)의 이해와 분류 모델별 비교 선택 전략
**분류 모델의 통계적 기초와 상황별 최적의 모델 선택법**

---

**데이터 분석 학습 과정에서 정리한 LDA(Linear Discriminant Analysis)의 핵심 개념과 로지스틱 회귀, SVM과의 차이점을 정리한 글입니다.** 
메타코드 강의 내용을 바탕으로 판별분석의 원리와 실무적 활용 방안을 체계적으로 요약하였습니다.

---

## 1. 판별분석(Discriminant Analysis)이란?

판별분석은 데이터의 그룹(클래스)을 구분하는 통계적 방법입니다. LDA는 그 중에서도 '평균'과 '분산'의 개념을 활용하여 집단을 가장 잘 구분해내는 직선(판별선)을 찾아냅니다.

### LDA의 핵심 원리
*   **평균의 차이 극대화**: 각 클래스별 데이터 분포의 평균을 구하고, 이 평균 사이의 거리가 가장 멀어지는 축을 찾습니다.
*   **분산의 최소화**: 같은 클래스 내에서의 분산은 최소화하여 각 집단이 뚜렷하게 뭉쳐 있도록 만듭니다.
*   **차원 축소**: 여러 변수를 하나의 선형 조합으로 합쳐 집단을 구분하므로, 분류와 동시에 차원 축소의 효과도 가집니다.

> **💡 판별식의 개수**
> 클래스가 2개(양성/음성)일 경우 이를 구분하는 판별식은 1개입니다. 만약 클래스가 K개라면, 판별식은 최대 (K-1)개까지 생성됩니다.

---

## 2. 실무에서의 LDA 활용 (특히 경영/마케팅)

LDA는 설명 가능성이 높고 통계적 근거가 명확하여 경영학 및 마케팅 분야에서 널리 쓰입니다.

*   **고객 세그먼트 구분**: 고가 브랜드 선호 고객 vs 저가 브랜드 선호 고객 분류
*   **이탈 예측**: 충성 고객 vs 이탈 가능 고객 구분
*   **구매 예측**: 특정 제품의 구매자 vs 비구매자 분류

## 3. 상황별 분류 모델 선택 전략 (LDA vs 로지스틱 vs SVM)

데이터의 특성과 분석 목적에 따라 적절한 모델을 선택하는 것이 중요합니다.

### ✅ LDA (Linear Discriminant Analysis)
*   **적합한 상황**: 
    *   표본 수가 적을 때 (특히 클래스별 데이터가 부족한 경우)
    *   독립변수가 연속형이고 정규분포를 따를 때
    *   클래스 간 공분산 구조가 유사할 때
*   **장점**: 통계적으로 안정적이며, 사후 확률 계산 및 해석이 용이함

### ✅ 로지스틱 회귀 (Logistic Regression)
*   **적합한 상황**: 
    *   정규성 가정이 부담스러울 때 (비정규 분포 데이터)
    *   독립변수에 범주형(Dummy) 변수가 포함되어 있을 때
    *   확률 해석(Odds Ratio)이 중요할 때
*   **장점**: 분포 가정이 필요 없으며 과적합 위험이 낮고 해석력이 매우 높음

### ✅ SVM (Support Vector Machine)
*   **적합한 상황**: 
    *   데이터가 선형적으로 분리되지 않아 복잡한 경계가 필요할 때
    *   변수의 개수(Feature)가 매우 많은 고차원 데이터일 때
    *   해석보다는 분류 정확도가 최우선일 때
*   **장점**: 커널 트릭을 통한 비선형 분류 가능, 일반화 성능이 뛰어남

---

## 4. 핵심 비교 요약표

| 비교 항목 | LDA | 로지스틱 회귀 | SVM |
| :--- | :--- | :--- | :--- |
| **주요 특징** | 통계적 모델 | 해석 중심 판별 모델 | 최적화 중심 ML 모델 |
| **적은 표본** | ✔ 강함 | 보통 | 약간 불안정 |
| **정규성 가정** | 필요 (최적 성능) | 필요 없음 | 필요 없음 |
| **확률 해석** | 용이 | 매우 용이 | 기본적으로 제공 안 함 |
| **비선형성 대응** | 불가 (기본) | 불가 (기본) | ✔ 가능 (커널) |
| **고차원 데이터** | 보통 | 보통 | ✔ 매우 강함 |

---

## 🎯 결론: 어떤 모델을 써야 할까?

1.  데이터가 크고 복잡하지 않으며 해석이 중요하다면? ➔ **로지스틱 회귀**
2.  표본이 적고 통계적 가정이 유효하다면? ➔ **LDA**
3.  정확도가 최우선이며 비선형 경계가 의심된다면? ➔ **SVM**

분석 환경이 **통계 및 이론 중심**이라면 LDA와 로지스틱 회귀를, **예측 정확도와 복잡한 데이터 대응 중심**이라면 SVM이나 앙상블 모델을 고려하는 것이 실전적인 접근법입니다.
