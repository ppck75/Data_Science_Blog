# 회귀 분석 (Regression) 핵심 정리

## 1. 선형 회귀 (Linear Regression)
선형 회귀는 종속 변수 y와 독립 변수 x 사이의 관계를 선형 결합으로 표현하는 모델이다

### 모델 수식
$$y = w_0 + w_1x_1 + w_2x_2 + \dots + w_nx_n + \epsilon$$

또는, 행렬 표현으로는 $y = XwT + \epsilon$로 표현할 수 있다. (X는 특성 행렬, w는 가중치 벡터)
> x와 w를 벡터로 취급해서 표현하면, 결국 우리가 알고 있던 선형회귀모델은 이렇게 표현할 수 있다.
> x = (x0 .... xn) 이고, w= (w0.... wn) 이기 때문에!
> x와 w의 내적이 선형회귀모델의 예측값이 된다. (h(x) = x.wT) 이러면 평소 우리가 알던 선형회귀모델과 동일한 형태가 된다. 그러므로 x와 wT의 곱 형태로 간단하게 나타낼 수 있는 것이다. 

* **Linear Model의 정의**: y가 가중치(w)와 특성(x)의 **선형 결합**으로 표현됨을 의미합니다.
* **주의사항**: 특성 변수 $x_i$ 자체가 비선형 결합일 수 있으나(Feature Engineering), $w$에 대해 선형이라면 여전히 Linear Model입니다.
    * **Linear Model 예시**: $y = w_0 + w_1\log(x_1) + 2w_2\sqrt{x_2}$    (log x1은 비선형 함수이지만, w1과 곱해져서 선형결합되어 있다.)
    * **Nonlinear Model 예시**: $y = w_0 + \exp(w_1x_1) + \log(w_2 + x_2)$ (가중치 $w$가 지수나 로그 안에 있음)
* > 이 말은 즉, 선형 결합이라고 해서, x도 선형이라는 보장은 없다는 것이다.
* > 선형 회귀는 모델이 선형이지만, 특성은 비선형일 수 있다. (Feature Engineering)
* > 파라미터와 변수가 결합할 때 선형이 된다면, 선형 모델이 된다. x3라는 새로운 변수를 x1과 x2의 곱 또는 로그 등등으로 만들어도, w3x3이라는 선형 결합이 된다면, 선형 모델이 된다.

## 2. 일반화 선형 모델 (Generalized Linear Model, GLM)
정답 y의 분포 가정에 따라 다양한 회귀 모델을 사용할 수 있다. 

| 분포 가정 (Distribution) | 예측값의 범위 (Real) | 모델 종류 |
| :--- | :--- | :--- |
| **Normal distribution** | $(-\infty, +\infty)$ | Linear Regression |
| **Bernoulli** | Binary: $\{0, 1\}$ | Logistic Regression |
| **Categorical** | Multiclass: $\{0, 1, 2, \dots, n\}$ | Softmax Regression |

y의 분포를 어떻게 가정하느냐에 따라서 모델이 달라진다. 예를 들어 y의 분포를 정규분포라고 가정하면 -> linear regression이 된다. y의 분포를 베르누이 분포라고 가정하면 -> logistic regression이 된다. y의 분포를 카테고리 분포라고 가정하면 -> softmax regression이 된다.

## 3. 비용 함수 (Cost Function) 정의
모델의 예측값과 실제값의 차이를 측정하기 위해 **평균 제곱 오차(MSE)**를 사용한다. (회귀 문제에서)

### Mean Squared Error (MSE)

$$J(w) = \frac{1}{m} \sum_{j=1}^{m} (\hat{y}^{(j)} - y^{(j)})^2 = \frac{1}{m} \sum_{j=1}^{m} (h(x^{(j)}) - y^{(j)})^2$$

* **행렬 표현**: $J(w) = \frac{1}{m} \sum_{j=1}^{m} (x^{(j)} \cdot w^T - y^{(j)})^2$
* **목표**: 비용 함수 $J(w)$를 최소화하는 최적의 가중치 $w^*$를 찾는 것
$$w^* = \arg\min_{w} J(w)$$

## 4. 최적의 가중치 $w^*$를 찾는 방법
단순히 무작위로 찾는 것(Random Search)보다 수학적인 방법을 사용합니다.
> 우리는 랜덤적으로 모두 해봐서 찾을 필요가 없다. 왜? 우리는 비용 함수를 미분할 수 있다는 것을 아니까! 또한, 미분을 했을 때 미분값이 0이 나오는 구간이 비용 함수가 최소가 되는 지점이라는 것을 알고 있기 때문에, 비용 함수를 미분해서 0이 되는 지점을 찾으면 된다. 그럼 이떄의 w는 최적의 w인 w*이다. 
> 물론, 이 방법은 선형회귀에서만 가능하고, feature의 갯수 또는 n이 커지면 복잡도가 늘어난다.
> 그래서 우리는 미분해서 한번에 구하는 방식이 아닌 Gradient Descent라는 방법을 사용한다.  (결국 미분을 이용하는 알고리즘이기는 함)

1.  **정규 방정식 (Normal Equation)**:
    * $\frac{\partial}{\partial w}J(w) = 0$이 되는 지점을 직접 계산
    * $w^* = (X^T X)^{-1} X^T y$
2.  **경사하강법 (Gradient Descent)**:
    * 기울기를 따라 점진적으로 하강하며 최솟값을 탐색
    * **전제 조건**: $J(w)$의 대부분의 점이 **미분 가능**해야 함

---

### 💡 보충 설명
* **$x \cdot w^T$**: 가설 함수 $h(x)$를 행렬의 내적으로 표현한 것이다. 
* **$\epsilon$**: 모델이 설명하지 못하는 잔차(Residual)를 의미한다.
