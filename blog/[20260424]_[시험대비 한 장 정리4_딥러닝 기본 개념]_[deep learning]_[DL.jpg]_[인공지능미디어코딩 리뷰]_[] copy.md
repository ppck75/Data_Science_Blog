# 딥러닝
퍼셉트론이란 초기 인공신경망. 뉴런: 신호를 받아 임계치 넘으면 다음 뉴런에게 전달 -> 입력값 x 가중치 합이 임계치를 넘으면 1 출력. z = w1 * x1 + w2 * x2 + b (선형 변환) y = f(z) (활성화 함수적용-비선형 변환 적용. 보통 계단 함수 사용) -> XOR 문제 풀 수 없음.
활성화 함수: 1. 시그모이드: 이진분류 출력층에 주로 사용, 역전파 과정에서 딥러닝 학습 이뤄지는데, 이때 연쇄법칙에 의해 각 층의 미분값을 계속 곱한다. 근데, 시그모이드의 미분 값은 최대가 0.25여서 작은 값들이 여러 층에서 곱해지면 앞쪽 층으로 갈수록 기울기는 사실상 0이 되기에 학습이 일어나지 않는다(출력이0이나1에 가까워지면 미분값이 거의 0이 된다) / 2. 소프트맥스: 다중 클래스 분류 출력층 / 3. 렐루: 기울기 소실 완화 위해 은닉층 사용(입력값이 0이하면 0, 0보다 크면 그대로 출력) 

단층퍼셉트론은 직선 하나로 구분할 수 없는 XOR 문제 해결 못함 - MLP
은닉층이 2개 이상인 MLP -> DNN. DNN을 학습시키는 것 -> 딥러닝 / 은닉층은 특징을 추출하는 층이다. 전결합층(밀집층)은 모든 뉴럭이 엊 늧으이 모든 뉴런과 연결된 층이다. FFNN 입력층-> 은닉층->출력층 방향으로만 연산이 진행되는 구조(예외: RNN은 은닉층 출력이 다시 은닉층 입력으로 순환. RNN은 FFNN이 아님)

학습방법: 1. 지도학습-레이블이 있는 데이터로 학습, 입력과 정답을 쌍으로 제공 2. 비지도학습-레이블없는 데이터로 학습 3.자기지도학습-데이터 자체에서 지도 신호를 생성. 대규모 레이블 없는 데이터 활용 가능 4. 강화학습-환경과상호작용하여 보상 최대화. 시행착오를 통한 최적의 행동전략 학습

검증용데이터: 학습 중간에 성능 정검, 평가용: 최종 성능 측정 / 배치크기: 한번에 모델에 넣는 데이터 수(데이터셋을 고정된 크기인 배치 사이즈로 나눈 그 그룹이 미니배치). 이터레이션: 1에프크를 끝내기 위한 배치 처리 횟수. 매 it마다 가중치 업데이트. 에포크: 전체 데이터를 1회 순전+역전파. 에포크가 너무 많으면 과적합 위험(에폭 끝나고 valid)

역전파란: 출력층, 은닉, 입력층 방향으로 거꾸로 계산하며 '가중치와 편향'을 업데이트하는 과정

기울기 소실: 시그모이드 미분값은 출력이 0이나 1에 가까우면 미분값이 거의 0에 가까워진다. w를 업데이트하는 역전파 과정의 핵심 원리인 '미분의 연쇄법칙'으로 각 가중치에 대한 미분값을 계산할 때 시그모이드 미분값 계속 곱하면 값이 작아지면서(층이 깊을수록 심각) 학습이 일어나지 않게 된다 (기울기 소실 문제는 ReLu를 사용하거나 잔차 연결을 통해 해결한다.)

GD - 학습률: 한번에얼마나이동할지결정 / 옵티마이저: 손실함수값을최소화하도록가중치를조정하는알고리즘. 단순경사하강법의문제(느린수렴, local minimum)를개선한 다양한변형존재. 
옵티마이저는 두 가지 방향 1. 스텝 방향 개선(모멘텀 계열) 2. 스텝 사이즈 개선으로 발전했다가 Adam으로 합쳐짐(모멘텀과 RMSProp 장점 결합 - 방향성 유지와 학습률 자동 조정)/ 모멘텀: 이전그래디언트의방향성을유지 관성처럼같은방향으로계속이동. 진동을줄이고빠르게수렴(방향의 일관성을 유지하게 해주는 옵티마이저이다. 학습 과정의 진동을 감소시키고 최저점까지 효율적으로 도달 할 수 있게 한다)

주요평가 지표: 정확도 - (TP + TN) / 전체(불균형 데이터에서 함정), 정밀도(재판) - TP / (TP + FP), 재현율(자율주행위험감지)- TP / (TP + FN), f1 score - 정밀도와 재현율의 조화 평균

딥러닝 작동 과정: 모델초기화,순전파,손실계산,역전파(각 가중치의 G계산),가중치업데이트(옵티마이저),반복(Iteration/Epoch)

과적합: 모델이 데이터의 노이즈까지 학습한 상태 - 해결방법: 데이터 양증가(데이터가 적으면 노이즈까지 학습하니까, 데이터증강, 이미지 회전 반전 크롭 등으로 확대), 드롭아웃(학습 중 일부 뉴런 무작위 비활성화,특정 뉴런 의존 방지,서로다른 신경망 앙상블 효과), Early Stopping(검증 오차가 증가하기 시작하면 학습 중단. 더 이상 학습해도 성능 나빠지는 시점 자동 감지), 가중치 규제(L1 L2규제로 가중치가 너무 커지는 것을 방지)

기울기 소실:역전파중그래디언트가점점작아져 입력층에가까운층의가중치가 거의업데이트되지않는문제 -> 즉, 마지막 loss 값 대비 거리가 먼 w(입력층과 가까운 가중치)는 학습되지 않는 문제 / 기울기 폭주: 그래디언트가 매우 큰 값으로 발산 --> 해결방법: 가중치 초기화, 배치 정규화, 레이어 정규화, ReLu 계열 은직층 사용, 잔차 연결, 그래디언트 클리핑
