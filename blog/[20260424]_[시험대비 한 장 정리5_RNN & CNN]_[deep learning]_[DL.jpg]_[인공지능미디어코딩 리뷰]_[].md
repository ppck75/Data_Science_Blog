# RNN
일반신경망(FFNN)는 입력 순서 고려x-모든 입력을 독립 처리,입력 길이가 고정되어야함. 시퀀스 데이터는 순서가 핵심 정보.
RNN(기억을 가진 신경망):ht(현재 은닉 상태. 현재의 기억) 한계: 기울기 소실 문제(역전파시 G가 시간에 따라 기하급수적으로 감소) -> 장기의존성 문제(시퀀스가 길어질 수록 초기 정보가 후반부에 미치는 영향이 사라짐) 즉, 앞의 단어의 정보가 담긴 Ht가 다음 단계로 넘어갈 때마다 정보가 희석되기 때문에 기억이 사라짐. -> 문제 해결 위해 Deep RNN, BiRNN(시퀀스를 양방향으로 처리하여 과거와 미래 정보를 모두 활용) -> LSTM GRU
RNN할용. 1-M: 이미지 캡셔닝, Mto1:감정분석, 텍스트 분류, MtoM(동일길이):품사 태깅, 개체명 인식, MtoM(seq2weq):길이 다를 수 있음. 기계번역, 요약 - 인코더가 입력 시퀀스를 압축하고 디코더가 출력 시퀀스를 생성
seq2seq:인코더(입력시퀀스를하나의고정길이벡터로압축-> context vector입력 문장 정보 압축한 벡터),디코더(context vector 받아서 시퀀스 생성.자기회귀적 생성) 한계: 입력 문장이 아무리 길어도 하나의 고정 길이 벡터에 정보 압축 -> 정보 손실(병목현상)에 따른 긴 문장 성능 저하 -> 어텐션 도입(디코더가 출력할 때마다 인코더의 모든 은닉상태 참조하여 관련 부분에 주목함. context vector하나에 의존 x -> 이후 트랜스포머로 발전)    결국 RNN의 발전 과정은 긴 문장에서 성능이 저하되는 장기의존성 문제(연쇄미분의 특성상 초기 w가 업데이트 되지 않는 문제)를 해결하기 위한 발전 과정이었다

# CNN
이미지 데이터의 구조: 3차원 텐서(높이,넓이,채널) 흑백은 28x23x1(채널1개) 컬러는 채널 3개. 각 픽셀은 0~255 정숫값을 가지며 이 숫자들의 패턴이 이미지임
일반 신경망으로 이미지 데이터 문제점 1. 파라미터 수 폭발(입력 뉴런 많이 필요 -> 과적합) 2. 공간적 관계(위치정보)가 무시된다(픽셀 위치 관계 소실)~~> CNN이 해결책: 커널로 이미지를 훑으며 지역적 특징을 추출(파라미터 공유: 같은 필터를 이미지 전체에 공유 -> 파라미터 감소, 공간적 구조 보존: 위치 관계 유지)
합성곱 연산: 입력 이미지 위에 커널을 슬라이딩하며 겹치는 부분끼리 곱하고 모두 더하는 연산이다. / 커널: 학습을 통해 최적화 되는 파라미터를 포함 / 특성맵: 커널을 통해 출력된 결과 데이터(커널을 통해 이미지 성격을 대표하는 feature를 뽑음. 이걸 담고 있는 map-> 공간적 특성). 각 커널이 다른 특징을 감지함. / 스트라이드: 필터를 이동하는 간격 / 패딩: 입력 데이터 주변을 0으로 채우는 것. 출력 크기(shape)를 입력과 동일하게 유지 / 필터가 감지하는 것: 초기층의 필터는 에지(edge)함. 깊은 층 필터는 점점 복잡한 형태 감지함. -> 층이 깊어질 수록 더 고수준의 특징을 추출함. / 컬러 이미지의 경우 필터도 3채널이며, 채널별로 합성곱 해서 결과를 더하여 하나의 피처맵을 만든다. 

CNN구조(net 붙으면 보통 CNN): 입력 이미지>합성곱+Relu(특징추출)>풀링(크기축소)>conv + pooling(점점 깊은 특징)>flatten(1차원 변화)>FClayer+소프트멕스(분류결과 출력) 풀링: 특성 맵의 크기를 줄이는 연산(중요한 특징은 유지하면서 불필요한 세부 제거함. 최대 풀링, 평균 풀링있음) / 전결합층: 합성곱+풀링으로 추출합 특성 맵을 1차원 벡터로 펼치로 FC layer에 인풋으로 넣는다. 
활용분야 1. 이미지 분류 2. 객체탐지(이미지 내 물체 위치 - 바운딩박스-와 종류 동시 판별) 3 .이미지 세분화(픽셀 단위 분류) 4. 미디어 연구 - 뉴스 영상 프레이밍, 소셜 미디어 이미지 분석(요즘은 트랜스포머로 이미지 처리함(vit)) 
YOLO-실시간객체탐지/이미지를 한 번만 보고 객체의 위치와 종류 동시 예측. 기존 R-CNN 계열은 느림(2단계 처리) -> yolo 방식: 이미지를 nxn 그리드로 분할하여 각 그리드 셀이 동시에 객체 예측-> 한번의 신경망 통과로 완료(실시간 처리 가능함) / 자율주행,cctv,미디어연구,의료 xray활용
YIT(CNN없이이미지분류-conv연산 아예X): 이미지를 고정크기의 패치로 나눔->각 패치를 1차원 벡터로 변환(flaaten)->각 패치 벡터를 임베딩 차원으로 선형 변환하고 위치인코딩 추가->패치의 순서(위치)정보 보존->트랜스포머인코더에 입력해서 패치 시퀀스를 NLP의 단어 시퀀스처럼 처리(셀프어텐션으로 패치끼리관계학습. 멀리 떨어진 패치도 직접 관련성 파악 가능)->bERT처럼 CLS토큰추가. 이토큰의 최종표현을FC레이어에 넣어 분류-> CNN 없이도 이미지 분류 성공! //의의: 이미지를 단어 시퀀스처럼 처리해서 성공>NLP와 컴퓨터 비전의 통합. 대규모데이터에 CNN보다 우수. 트랜스포머가 NLP vision까지 지배.
RNN은 은닉 상태로 이전 정보를 기억하고, CNN은 수용영역 내 공간 패턴을 기억함
RNN은 병렬 처리 어려움(순차처리) CNN은 필터 동시 적용하기에 병렬처리 가능
RNN과 CNN 모두 트랜스포머에 의해 대체되고 있다.
